# ADR-0055: Nginx передаёт медиа, FastAPI проверяет бизнес-правила

Статус: принято пользователем 2026-11-14; Q05 по медиараздаче закрыт.

## Решение

FastAPI проверяет публикацию, готовность, скрытие и права каждого запроса.
После разрешения X-Accel-Redirect направляет Nginx к внутреннему пути RustFS.
Байты сегментов, init, WebP и WebVTT не проходят через Python. Небольшие HLS-
плейлисты формируются сервером из проверенных результатов конвейера.

RustFS остаётся закрытым; внутренние подписанные адреса не выдаются браузеру.
Внешние ссылки принадлежат конкретной публикации, а не общему физическому
объекту. Разрешения не кэшируются: отзыв, private и hidden проверяются снова
на последующих запросах. Уже переданные байты не отзываются.

Новых сервисов или библиотек нет. Для внутренней подписи используется уже
согласованный срок подписанных S3-запросов из ADR-0038; он не даёт клиенту
период обхода авторизации, поскольку внутренний маршрут недоступен извне.

Подробности реализации/проверки — [доставка медиа](../backend/media-delivery.md).
Источники, проверены 2026-11-14:
[X-Accel-Redirect](https://nginx.org/en/docs/http/ngx_http_proxy_module.html#proxy_ignore_headers),
[internal](https://nginx.org/en/docs/http/ngx_http_core_module.html#internal).
