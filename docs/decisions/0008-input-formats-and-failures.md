# ADR-0008: входные форматы и ошибки обработки

Статус: принято пользователем. Дата: 2026-11-12.
Закрывает бизнес-части Q02 и Q03; их технические части пока отложены.

## Контекст

Нужно было определить набор принимаемых видеофайлов и результат окончательной
ошибки обработки. Пользователь выбрал открытый набор форматов вместо списка
расширений и подтвердил доступность уже готовых качеств при частичном сбое.

## Решение

Принимаются видеофайлы любого формата, которые используемая сборка FFmpeg
может корректно прочитать и обработать, с учётом согласованных лимитов.
Видеодорожка обязательна, аудиодорожка — нет. Не обещается обработка произвольного
содержимого: неподдерживаемый или повреждённый файл получает понятную ошибку.

После окончательной ошибки отдельного качества готовые варианты доступны
с учётом прав и модерации. Если не готово ни одного, просмотр закрыт,
автору показывается причина ошибки. Канонические правила — в
[конвейере](../backend/video-pipeline.md).

## Последствия

Расширение файла не является единственным основанием допуска или отказа.
Успешная передача исходника и готовность видео к просмотру — разные результаты.
Библиотеки, параметры повторов и профили кодирования не выбраны.
[Открытые вопросы](../tasks/open-questions.md). Реализация ещё не начата.
