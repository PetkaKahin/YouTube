# ADR-0006: сохранность обработки и качество аудио

Статус: принято пользователем. Дата: 2026-11-11.
Уточняет Q02 и требования к обработке видео из [ADR-0001](0001-foundation.md);
включает последующее согласование и закрытие Q12.

## Контекст

Задания обработки нельзя терять, а сбой одного качества не должен требовать
повторного создания всех остальных. Пользователь также уточнил, что для низких
качеств нужно снижать качество аудио вместе с изображением.

## Решение

Очередь хранится в PostgreSQL. Каждое качество видео имеет отдельную задачу
и отдельно сохранённый результат. Для низких качеств облегчается и аудиодорожка.
Канонические правила — в [конвейере](../backend/video-pipeline.md).

При дальнейшем разборе Q12 пользователь уточнил три уровня аудио: сильное
сжатие для 360p, умеренное для 480p и обычное качественное аудио с 720p.
Видео без аудиодорожки разрешены для загрузки и просмотра без звука.

## Последствия

Потеря Valkey не теряет очередь. Ошибка одного качества не уничтожает готовые
варианты; повторяется обработка только неуспешного качества.
Низкое качество должно экономить трафик как изображения, так и звука.
Q12 закрыт. Отсутствие аудиодорожки не должно приводить к отказу в обработке
или публикации, если остальные требования к файлу выполнены.
Поведение после окончательного сбоя согласовано 2026-11-12 в
[ADR-0008](0008-input-formats-and-failures.md); бизнес-часть Q02 закрыта.

Пользователь ограничил текущий разбор бизнес-правилами. Конкретные библиотеки,
кодеки, битрейты и параметры исполнения отложены до технического этапа;
новые библиотеки этим решением не выбраны. [Открытые вопросы](../tasks/open-questions.md).
Реализация ещё не начата.
