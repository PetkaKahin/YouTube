# ADR-0012: начальный порядок главной и поиска

Статус: принято пользователем. Дата: 2026-11-12.
Частично закрывает Q08; включает последующее закрытие Q15 о смысле даты добавления.

## Контекст

Нужно определить начальный порядок ленты и результатов поиска в учебном проекте.
Пользователь выбрал дату добавления и дополнительно запросил разные сортировки поиска.

## Решение

Главная пока работает без алгоритма рекомендаций: новые видео первыми по дате
добавления. Поиск идёт по части названия без учёта регистра, по умолчанию
с тем же порядком. Затем пользователь подтвердил, что дата добавления видео —
успешное завершение загрузки исходного файла, даже если публикация происходит позже.
Q15 закрыт. Набор фильтров и двух сортировок поиска выбран позднее в
[ADR-0013](0013-search-filters.md).
Канонические правила — в [Video](../backend/modules/video.md) и [поиске](../project/search.md).

## Последствия

Любая сортировка сохраняет фильтры готовности, публичности и модерации.
Создание черновика, завершение загрузки и публикация могут происходить в разное
время. Для порядка видео выбрано завершение загрузки; последующая готовность
качеств и публикация не меняют дату добавления.

Детали UI и библиотек отложены. [Открытые вопросы](../tasks/open-questions.md).
Реализация ещё не начата.
