# ADR-0061: очередь модерации и причины скрытия

Статус: принято пользователем. Закрывает Q45.

Ожидающие жалобы показываются старыми первыми, по актуальному времени
отправки; при равном времени — по ID по возрастанию. Повторная отправка
обновляет время существующей записи, поэтому переносит её к более новым
обращениям. Cursor по 20 сохраняется по ADR-0059.

Причина скрытия выбирается из тех же шести готовых вариантов, что причина
жалобы: спам/мошенничество, оскорбления/травля, насилие, сексуальный контент,
авторские права, другое. Свободный текст и его лимит не нужны.
Пользователь допустил добавление фильтров позднее; текущая реализация их
не добавляет без отдельной задачи.

Правила и контракт — [модерация](../backend/moderation.md).
