# ADR-0040: оригинал только для обработки и дедупликации

Статус: принято пользователем 2026-11-13; Q38/Q39 закрыты.
Уточняет [ADR-0039](0039-av1-encoding.md) и заменяет часть
[ADR-0031](0031-global-shared-media.md) о постоянном хранении исходников.
Медиаконвейер подключён частично; [постоянная очистка](../backend/original-cleanup.md)
после завершения зависимых работ реализована в B19.

## Решение

- Загруженный оригинал хранится временно: он нужен для доверенного вычисления
  слепка дедупликации и перекодирования. Постоянный архив оригиналов не создаём.
- Оригинал сохраняется до полной готовности видео и завершения всех зависимых
  работ, включая проверку слепка, качества, превью и существующие субтитры.
  Как только он больше не нужен для этих работ и их повторов, его удаляем.
  Готовность первого качества или возможность раннего просмотра недостаточны
  для удаления исходника.
  Постоянные видеоварианты — только AV1 по ADR-0039. Входной файл не требуется
  заранее переводить в AV1 до вычисления слепка исходных сжатых дорожек.
- Слепок и необходимые технические сведения для распознавания повторной
  загрузки сохраняются отдельно от удаляемого оригинала. Подтверждённый дубль
  переиспользует совместимые готовые результаты без повторного кодирования.
- Дедупликация готовых результатов/превью, учёт пользовательских ссылок
  и независимые права публикаций из ADR-0031 сохраняются. Временный оригинал
  нельзя удалять, пока от него зависят выполняющиеся работы.
- Другие видеокодеки и автоматическое перекодирование из AV1 сейчас
  не реализуем. Пользователь не планирует смену кодека для тестового задания.

## Ошибки и повторы

R17 предусматривает будущий ручной повтор упавших задач. После удаления
оригинала у полностью неуспешной обработки может не остаться входных данных
для повтора. Готовое низкое качество также не заменяет исходник для
восстановления высокого качества без увеличения разрешения или потерь.

Пользователь подтвердил: оригинал нужен, пока задача полностью не выполнена.
При частичной или полной ошибке он сохраняется для последующего повтора;
исчерпание автоматических попыток само по себе не разрешает удаление.
Срок автоматического удаления невыполненного исходника не вводится.
Правила очистки подтверждённого дубля должны учитывать, что необходимый
совместимый результат действительно готов, а зависимых работ больше нет.

Очередь и временные входные данные обработки не зависят от Valkey или
локального диска worker. Повтор после рестарта не должен терять нужный ему
входной файл до согласованной точки очистки.
