# ADR-0067: загрузка видео в модалке Studio

Статус: принято по референсам и уточнению пользователя 2026-11-16;
первый этап F22–F25 реализован.

## Решение

«Создать» → «Добавить видео» открывает модалку загрузки. Пользователь передал
снимки выбора файла, информации, дополнений и доступа и разрешил убрать лишнее.
Источники — [каталог референсов](../frontend/references.md#загрузка-видео-studio).

Оставляем выбор одного файла, «Информация» и «Доступ». Не переносим дополнения,
предварительную проверку YouTube, импорт сведений, A/B-тесты, интерактивные
заставки/подсказки, премьеру, расписание, unlisted-видео и юридические ссылки YouTube.
Субтитры берутся из исходника, как уже задано ТЗ.
Превью, выбор плейлистов и разрешения по email остаются требованиями F26–F28;
первый этап загрузки не объявляет их реализованными.

Название/описание и явный выбор public/private сохраняют
[ADR-0037](0037-video-metadata.md). Поэтому передача начинается после заполнения
информации и выбора доступа, по нажатию «Сохранить». Затем последовательно
создаются черновик, передача и серверное подтверждение исходника, публикация.
Завершение передачи и готовность обработки — разные состояния.
Публикация не требует ждать всех качеств; просмотр предлагается только при
готовом варианте и известных разрешающих состояниях сервера.

## Надёжность и границы

Повтор после ошибки в открытой форме использует тот же File, черновик и upload_id;
API обновляет ссылки только недостающих частей. После создания черновика нельзя
подменить исходник другим файлом. При уходе запросы/передача отменяются на клиенте,
серверные черновики не удаляются. Обычная серверная очистка незавершённых передач
остаётся действующей; отмена с удалением и pause/resume не добавляются.

File и подписанные ссылки не сохраняются в браузерные хранилища или QueryCache.
URL содержит только точный ID видео и позволяет заново прочитать подтверждённые
метаданные/состояние. Если после обновления страницы исходник ещё не принят,
предлагается начать отдельную загрузку: размер нового File не доказывает,
что он совпадает с прежним, а склеивать его с принятыми частями нельзя.

Код, проверки, оставшаяся работа — [загрузка на фронтенде](../frontend/upload.md).
