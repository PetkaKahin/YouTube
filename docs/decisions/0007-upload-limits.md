# ADR-0007: лимиты загрузки и исходники ниже 360p

Статус: принято пользователем. Дата: 2026-11-11.
Уточняет бизнес-часть Q03 и лестницу качеств из [ADR-0001](0001-foundation.md).

## Контекст

Лестница обработки начинается с 360p. Нужно было определить поведение для
меньшего исходника и пределы загрузки для учебного проекта.

## Решение

Исходный файл ограничен 5 ГБ и 60 минутами. Оба ограничения действуют одновременно.
Видео ниже 360p принимается и обрабатывается в исходном разрешении, без увеличения.
Сжатие сильное, но сохраняет разборчивость исходного изображения.
Канонические правила — в [конвейере](../backend/video-pipeline.md).

## Последствия

Проверка низкого разрешения не должна отклонять допустимое видео. Нужен вариант
ниже стандартной лестницы с фактическим разрешением. Для сжатия важен результат
на изображении; численные параметры выбираются позднее на техническом этапе.
Пределы проверяются сервером, превышение не исправляется обрезкой видео.

На момент принятия в бизнес-части Q03 оставались входные форматы.
Они согласованы 2026-11-12 в [ADR-0008](0008-input-formats-and-failures.md);
бизнес-часть Q03 закрыта, техническая часть отложена.
[Открытые вопросы](../tasks/open-questions.md). Реализация ещё не начата.
