# ADR-0050: ресурсы медиаворкера задаются конфигурацией

Статус: подход принят пользователем 2026-11-13; численные пределы
и поведение ограничителя позднее приняты в [ADR-0051](0051-media-resource-limits.md). Дополняет
[ADR-0035](0035-worker-policy-and-job-errors.md).

## Решение

- Число потоков/параллелизм обработки подстраиваются под CPU, реально
  доступные контейнеру. Одного числа CPU хоста недостаточно: учитываются
  CPU quota и affinity/cpuset. Жёсткую квоту CPU обеспечивает Docker.
- Бюджеты RAM, временного диска и таймауты задаются несекретной конфигурацией
  и могут меняться под сервер. Секреты по-прежнему только в Compose Secrets.
- Одна тяжёлая задача на worker, heartbeat, recovery и повторы сохраняют ADR-0035.
  Привязки к GPU/модели процессора нет; программная основа — ADR-0046.
- До зависимой реализации значения и реакция на превышение обсуждаются
  по замерам. Короткие синтетические пробы не являются production-лимитами.

## Техническая квалификация

Методика, источники, результаты и ограничения —
[ресурсы медиа](../backend/media-resources.md).
Этот этап не меняет БД, бизнес-логику, HTTP или работающий worker загрузок;
тяжёлый worker ещё не подключён.
