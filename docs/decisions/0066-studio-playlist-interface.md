# ADR-0066: Studio для создания и редактирования своего контента

Статус: принято и уточнено пользователем 2026-11-16; первый этап F21 реализован.

## Решение

Studio — отдельная область создания/редактирования своего контента в рамках ТЗ
(F21–F28). Публичный собственный канал выглядит как канал другого автора:
без таблиц владельца, private/unlisted-плейлистов, форм и кнопок управления.
Действующие бизнес-права, включая запрет подписки на себя, сохраняются.

Личный список плейлистов внутри Studio оформляется по предоставленному снимку:
раздел «Контент на канале», вкладка «Плейлисты», таблица с названием/описанием,
доступом и датой последнего изменения. Это уточняет ранее открытое размещение
F21 в Q07; предложение отдельного обычного списка «Мои плейлисты» не принято.

Референс — [снимок Studio](../../frontend/Reference/clipboard_2026-11-16_16-15.png).
Сохраняются Vue, SCSS, тёмная тема и функции нашего ТЗ. Полный набор разделов
Studio, аналитика, просмотры и другие расширения не добавляются из-за снимка.
Изображения и метрики, отсутствующие в контракте, не имитируются.

## Создание плейлиста

Пользователь передал раскрытое [меню «Создать»](../../frontend/Reference/clipboard_2026-11-16_16-25.png)
и [исходную модалку](../../frontend/Reference/clipboard_2026-11-16_16-26.png):
«Создать» → «Создать плейлист» → «Новый плейлист». Название обязательно,
описание необязательно; по умолчанию выбран «Открытый доступ» (`public`).
Также доступны «Доступ по ссылке» и «Ограниченный доступ». Это закрывает
вопрос расположения формы и начальной видимости F21 в Q07.

В рамках ТЗ модалка содержит только название, описание и доступ. Порядок
включения видео уже задан ТЗ; выбор другой сортировки, языка и добавление видео
непосредственно при создании плейлиста не добавляются. Состав выбирается
в настройках своего видео F28. В меню остаются только реализованные действия.

## Границы первого этапа

Личный список всех трёх режимов и создание подключены к существующему API в
`/studio/content/playlists`; вход из меню аккаунта «YouTube Studio».
Код и проверки — [Studio](../frontend/studio.md). Публичный канал сохраняет
обычный интерфейс; переход к разрешённому плейлисту использует общий маршрут.
Остальные экраны создания/редактирования уточняются по ходу соответствующей
работы. Мобильного референса Studio ещё нет; текущая адаптация проверяет
достижимость действий, без заявления о полной визуальной приёмке.
