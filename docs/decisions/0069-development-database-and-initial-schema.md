# ADR-0069: подключение IDE и начальная схема тестовой БД

Статус: принято пользователем 2026-11-18. Текущая БД полностью тестовая;
её разрешено пересоздать. Уточняет локальное хранение пароля из
[ADR-0019](0019-compose-secrets.md), не меняя передачу секретов сервисам.
Хранение копии пароля в `.env` впоследствии отменено
[ADR-0070](0070-secret-files-only.md); ниже сохранено первоначальное решение.

## Решение

В dev PostgreSQL публикуется на `127.0.0.1:${POSTGRES_PORT:-5432}`.
Внутри Docker адрес остаётся `postgres:5432`; в prod порт не публикуется.
В локальном игнорируемом `.env` доступны POSTGRES_PORT, POSTGRES_DB,
POSTGRES_USER и копия POSTGRES_PASSWORD для подключения из IDE.
`init` берёт пароль из существующего Compose Secret либо создаёт его вместе
с файлом при первой установке. Существующий пароль автоматически не ротируется.
`.env` остаётся с правами 0600; значения не печатаются в логах и не передаются
через Compose environment, build args, frontend или Git. Остальные секреты
по-прежнему находятся только в Compose Secrets.

История разработки 0001–0028 заменяется начальной схемой: отдельная миграция
создаёт таблицу сразу со всеми колонками, проверками и индексами.
Взаимозависимые video_encoded_tracks/video_thumbnail_uploads находятся вместе;
их циклический внешний ключ добавляется после создания обеих таблиц.
Схемой очереди владеет Procrastinate: её установка — отдельная миграция,
при downgrade история очереди сохраняется, как раньше.
Миграции содержат статические определения и не импортируют текущие ORM-модели.
Переход со старых ревизий выполняется через `make refresh`, без переноса данных.
На текущем тестовом этапе структуру можно править в начальных миграциях
с пересозданием БД; после появления данных, которые требуется сохранять,
потребуются отдельные миграции изменений.

## Проверка

Сравнить итоговую схему до и после свёртки, проверить upgrade/downgrade/upgrade,
ограничения и индексы, затем `make refresh`, подключение по опубликованному порту
с паролем из `.env` и затронутый сценарий `install.sh`. Бизнес-логика и API не меняются.
