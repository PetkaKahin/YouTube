# ADR-0052: основные видео- и аудиодорожки

Статус: принято пользователем 2026-11-14; Q40 закрыт.

Для готового результата выбирается одна обычная видеодорожка, без attached_pic,
и одна аудиодорожка, если звук есть. Сначала выбирается default, иначе первая
по порядку потоков; при нескольких default — первая из них.
Остальные видео-/аудиодорожки не конвертируются. Переключение аудиодорожек
не добавляется. Все поддерживаемые встроенные текстовые субтитры сохраняют
правила [ADR-0049](0049-embedded-text-subtitles.md).

Слепок исходника по-прежнему учитывает весь состав, а общие результаты
конвертации связываются с выбранными дорожками и совместимым профилем.
Выбор не зависит от имени файла, языка HTTP-запроса или описательных тегов.
