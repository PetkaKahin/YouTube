# ADR-0042: битрейты AAC-LC по качествам видео

Статус: принято пользователем 2026-11-13; аудиопрофиль согласован.
Кодирование ещё не реализовано.
Уточняет [ADR-0041](0041-aac-lc-audio.md) и прежнюю градацию аудио
из [ADR-0006](0006-video-jobs-and-audio.md): с 1080p появляется повышенный уровень.

## Решение

Пользователь принял предложенные битрейты и поручил поднять качество звука
для 1080p и выше до 240 кбит/с. Значения — целевой битрейт всей дорожки,
а не каждого канала отдельно.

| Качество видео | Моно, кбит/с | Стерео, кбит/с |
| --- | --- | --- |
| 360p и ниже | 32 | 64 |
| 480p | 48 | 96 |
| 720p | 80 | 160 |
| 1080p, 1440p, 2160p | 120 | 240 |

Пользователь подтвердил общее правило: битрейт моно вдвое ниже стерео
для каждого качества, включая 120 кбит/с для моно 1080p+.

AAC-LC, максимум стерео с сохранением моно и отсутствие искусственного
звука у беззвучных видео остаются по ADR-0041.
Частота дискретизации — **48 кГц для всех качеств**. Встроенный кодировщик
`aac` работает в режиме CBR с явным `-b:a` по таблице; VBR по параметру
качества не включаем. Это режим управления битрейтом кодировщика,
а не обещание одинакового размера каждого AAC-пакета или HLS-сегмента.
Описание режимов — [FFmpeg, AAC](https://ffmpeg.org/ffmpeg-codecs.html#aac),
проверено 2026-11-13. Числовые настройки приняты
как целевые параметры, а не как результат измерения качества или совместимости.

## Приёмка будущей реализации

Проверить соответствие профиля качеству видео и числу выходных каналов,
отсутствие добавленного звука у беззвучного исходника, корректный downmix
и фактические качество/битрейт готового результата. Стереодорожка 1080p+
не должна оставаться на профиле 160 кбит/с для 720p.
Проверить выходные 48 кГц, профиль AAC-LC и параметры режима CBR;
все входные частоты приводятся к согласованной выходной частоте.
