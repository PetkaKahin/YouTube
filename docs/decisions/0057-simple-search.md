# ADR-0057: простой поиск с cursor-пагинацией

Статус: принято пользователем; Q08 закрыт для поиска видео и каналов.

Поиск по буквальной части названия видео, имени или @тега канала без учёта
регистра. Запрос после удаления крайних пробелов — 1–100 символов, пустой
отклоняется. Cursor возвращает порции по 20 результатов. Согласованные фильтры,
сортировки, периоды МСК и правила доступа сохраняются; ранжирование по
релевантности, новый поисковый движок и дополнительные функции не вводятся.

Поиск плейлистов добавляется после их реализации. Параметры других списков
остаются открытыми. Контракт, границы и проверки — [поиск](../backend/search.md).
