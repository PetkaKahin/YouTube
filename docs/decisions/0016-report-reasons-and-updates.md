# ADR-0016: причины и обновление жалоб

Статус: принято пользователем. Дата: 2026-11-12.
Закрывает оставшуюся бизнес-часть Q08 и включает последующее закрытие Q19.

## Контекст

Нужно определить причины жалоб и поведение при повторной отправке.
Пользователь подтвердил базовый список причин и уточнил обновление записи.

## Решение

Причины: спам/мошенничество, оскорбления/травля, насилие, сексуальный контент,
авторские права и другое. На пару «пользователь, видео» хранится одна жалоба;
повторная отправка обновляет эту запись, в том числе после рассмотрения.
При последующем уточнении пользователь подтвердил: рассмотренная жалоба
после обновления снова ставится в очередь модерации, без создания новой записи.
Канонические правила — в [Moderation](../backend/modules/moderation.md).

## Последствия

Повтор не создаёт новые жалобы от одного пользователя на то же видео.
Обновление обращения само по себе не скрывает и не открывает видео.
Обновлённая рассмотренная жалоба снова ожидает решения модератора.
Повтор уже ожидающего обращения не создаёт второй записи в очереди.
Q19 закрыт; остальные детали UI и технической реализации отложены.
