# ADR-0029: идентификаторы bigint

Статус: принято пользователем 2026-11-13, Q30 закрыт.

## Решение

Идентификаторы бизнес-сущностей — простой PostgreSQL `bigint`, генерируемый
базой данных. В Python это `int`, в OpenAPI — `integer/int64`.
Первое применение — аккаунт и канал в B01.

## Последствия

UUID и отдельный сервис генерации идентификаторов не требуются.
Предсказуемость номера не даёт полномочий: каждый защищённый сценарий проверяет
серверную личность и права независимо от идентификатора.
