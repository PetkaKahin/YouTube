# ADR-0009: приватный доступ по email

Статус: принято пользователем. Дата: 2026-11-12. Закрывает Q04 и возникший Q13.

## Контекст

Нужно выбрать адресата разрешения на приватное видео. Пользователь выбрал email
и запретил раскрывать, зарегистрирован ли адресат в проекте.

## Решение

Владелец добавляет любой корректный по формату email, в том числе до регистрации
получателя. Ответ и поведение формы не раскрывают существование аккаунта.
Разрешение адресовано email и не требует выбора существующего пользователя.
Канонические правила — в [Video](../backend/modules/video.md).

При последующем разборе Q13 пользователь подтвердил: в учебном проекте доверяем
email, введённому при регистрации, и не подтверждаем почту перед приватным
просмотром. Получатель должен войти в аккаунт с разрешённым email.

## Последствия

Список разрешений хранится независимо от наличия аккаунта получателя.
API и UI не возвращают данные найденного по адресу аккаунта или статус его
регистрации. Гостевой просмотр приватного видео этим решением не разрешается.

Q13 закрыт: проверка владения почтой не входит в проект; для определения
получателя достаточно совпадения нормализованного адреса его аккаунта с
разрешением. Пользователь принял это упрощение для учебного проекта.
Проверки готовности видео, видимости и модерации сохраняются.

реализованы с миграцией 0015; защищённая медиараздача ещё впереди.
