# ADR-0024: public зависит только от собственных domain и application

Статус: принято пользователем 2026-11-13. Уточняет
[ADR-0023](0023-module-boundaries.md) и отменяет сборку адаптеров через `public`.

Дополнение: [ADR-0027](0027-explicit-module-providers.md) сохраняет правило `public`,
закрывает Q29 и разрешает только техническому реестру импортировать классы
провайдеров инфраструктуры. Формулировки об открытом Q29 ниже относятся к моменту
принятия ADR-0024.

## Решение

- `<module>.public` импортирует только собственные `domain` и `application`
  и стандартную библиотеку Python.
- Собственная `infrastructure`, чужие модули, `common` и сторонние библиотеки
  не являются зависимостями `public`. Контроллеры по-прежнему вызывают модули
  через их публичные контракты; исключений для `app` нет.
- `public` не создаёт конкретные репозитории, не регистрирует ORM metadata
  и не собирает инфраструктурные зависимости. Прежнее разрешение в Tach
  и положительная проверка такой сборки были ошибкой прежней схемы.
- Tach сохраняется: явные зависимости, видимость и ограничения внешних
  импортов выражают новое правило. Замена инструмента нужна только если
  он не сможет обеспечить согласованные ограничения; такого препятствия
  в этой настройке не выявлено.

## Последствия

В репозитории пока нет реальных фасадов и фабрик бизнес-модулей, поэтому
ужесточение не меняет работающие HTTP-сценарии, БД и конфигурацию ресурсов.
Публичные контракты больше не служат точкой сборки инфраструктуры.

**До реализации DI остаётся Q29:** определить сборку конкретных адаптеров
при сохранении закрытых внутренних пакетов и чистого `public`. Место сборки
и механизм регистрации не выбраны. Скрытые импорты, регистрация через
`__init__`, динамическое обнаружение или исключение для `app` этим решением
не вводятся. Этот будущий вопрос не блокирует текущую проверку импортов:
сборка модулей сейчас не реализуется.

Источники: [конфигурация Tach](https://docs.gauge.sh/usage/configuration/),
проверена 2026-11-13; поведение подтверждается тестами установленного Tach 0.35.3.
