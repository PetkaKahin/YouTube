# ADR-0053: AV1 для кадров со стороной меньше 64 пикселей

Статус: принято пользователем 2026-11-14; Q41 закрыт, исключение к ADR-0039.

Установленный SVT-AV1 2.3.0 требует ширину и высоту не меньше 64.
Увеличивать исходник ради этого ограничения нельзя. Если после расчёта качества
хотя бы одна сторона меньше 64, используем уже установленный программный
`libaom-av1`: `cpu-used=4`, однопроходный CRF по таблице ADR-0043,
без целевого битрейта. Для остальных размеров — SVT-AV1, preset 6, tune=0.
Готовый видеокодек остаётся AV1, CPU/Docker и остальные профили не меняются.

В Docker проверены отказ SVT для 32×48, успешные SVT 64×64/96×64 и libaom
32×48 с сохранением размеров. Это проверка возможности; значения CRF разных
кодировщиков не обещают одинаковой визуальной ошибки. Разборчивость и размер
маленьких результатов проверяются при реализации без самовольной смены профиля.

Последующая реализация включает реальные задания и автоматическую проверку
разборчивости/размеров малых кадров — [кодирование](../backend/encoding.md).
