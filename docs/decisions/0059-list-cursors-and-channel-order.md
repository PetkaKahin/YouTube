# ADR-0059: cursor по 20 для всех списков и порядок канала

Статус: принято пользователем; Q08 закрыт для способа пагинации и размера
порции всех списков, включая будущие комментарии и модерацию.

Все списки используют cursor-пагинацию по 20 элементов. Это обобщает
ранее принятые ADR-0056–0058; повторно выбирать пагинацию перед каждым API
не требуется. Прочие ограничения и бизнес-правила будущих API разбираются
перед их реализацией.

Видео на канале идут новыми первыми по успешному завершению загрузки,
как на главной; публичные плейлисты — по созданию, новые первыми.
При одинаковой дате используется id DESC. Поздняя публикация или обработка
не поднимает видео. Состав плейлиста не меняет порядок списка плейлистов канала.

Правила публичности сохраняются: на канале только public-плейлисты и
public/published/visible видео с готовым качеством. Владелец и приглашённый
не получают дополнительных результатов публичного списка.
Контракт реализации — [страница канала](../backend/channel-page.md).
