# ADR-0031: глобальные общие медиаобъекты

Статус: принято пользователем 2026-11-13; уточняет ADR-0030, закрывает Q31/Q32.
Общие записи слепков/дорожек и ссылки передач реализованы частично —
[проверка исходника](../backend/track-fingerprints.md).
Подключены общие [AV1/AAC](../backend/encoding.md) и
[превью](../backend/thumbnails.md); публичная выдача ещё впереди.
Критерий идентичности уточнён в ADR-0032: Q33 закрыт,
основа слепка Q34 позднее выбрана в ADR-0033.
Часть о постоянном хранении исходников заменена
[ADR-0040](0040-temporary-originals.md): оригиналы временные,
постоянные видеоварианты — AV1. Остальные правила общих результатов сохраняются.

## Решение

- Физическая дедупликация общая для всех аккаунтов. На один физический контент
  могут ссылаться многие пользователи как создатели своих логических видео.
  Копирование контента другим пользователем не должно создавать вторую
  постоянную физическую копию одинакового содержимого.
- Общими становятся исходник и совместимые готовые результаты обработки,
  включая HLS и превью. Превью также подлежат дедупликации: малый размер
  отдельного изображения не отменяет экономию места при большом числе объектов.
- Контент сохраняется, пока на него ссылается хотя бы один пользователь.
  Освобождение ссылки одного пользователя не удаляет данные остальных.
  Основанием очистки физической копии может быть только отсутствие всех
  действующих пользовательских ссылок на неё.
- Метаданные, авторство логической публикации, видимость, разрешения и состояние
  модерации остаются независимыми. Наличие общей физической копии не раскрывает
  чужие видео и не открывает доступ к их публикациям.

## Последствия для проектирования

Физический объект не принадлежит исключительно первому загрузившему аккаунту.
Учёт ссылок и очистка должны выдерживать параллельное добавление/освобождение
ссылок и повтор выполнения фоновой задачи. Нельзя удалить объект по устаревшему
снимку отсутствия ссылок, если к нему уже добавлена новая ссылка. Готовые
результаты переиспользуются при совместимых параметрах обработки; один объект
хранилища не привязывается к правам единственного логического видео.

Правило времени жизни не добавляет само по себе HTTP/UI удаления видео:
эти операции в исходном ТЗ отсутствуют и отдельно не запрашивались.

## Уточнение критерия совпадения

Пользователь выбрал побайтовое содержимое дорожек без описательных метаданных
контейнера; отдельные ссылки источников и точный критерий закреплены в
[ADR-0032](0032-source-links-and-track-fingerprints.md). Техническая основа слепка
выбрана в [ADR-0033](0033-compressed-content-fingerprints.md). Доверенная серверная проверка и прямая загрузка
сохраняются по ADR-0030.
