# ADR-0054: выбор превью и собственные изображения

Статус: принято пользователем; Q42/Q43 закрыты.
Бэкенд подключён: [состояние и проверки](../backend/thumbnails.md).

Владелец выбирает один из трёх случайных кадров видео либо загружает собственное
изображение. До ручного выбора используется первый кадр. Это явное расширение
прежнего B16, не включавшего загрузку своего превью. Редактор не добавляется.

Результат — WebP, качество 80, вписывание в 1280×720 без увеличения, обрезки
или искажения пропорций. Поворот/SAR учитываются, HDR преобразуется в SDR.
Для своего изображения нет списка расширений: нужен успешный разбор установленным
декодером. Вход ограничен 10 МиБ и 40 мегапикселями, анимация не принимается.
Повреждённые и неподдерживаемые изображения получают безопасную ошибку.

Общие кадры/изображения подчиняются ADR-0031; выбор независим у публикаций.
Повтор обработки не меняет уже предложенную тройку и выбор владельца.
Загрузка нового изображения не открывает доступ к чужому и не удаляет
текущее готовое превью до успешного завершения. Запоздавшая работа не заменяет
более новый выбор. Готовность превью сама по себе не публикует видео.

Порядок реализации: постоянные данные → сценарии → CPU-обработчик/очередь/RustFS
→ API владельца → проверки Docker. Подготовка изображения проверяет геометрию
и отсутствие второго кадра, нормализует пиксели и вычисляет слепок до WebP;
совместимый готовый результат не кодируется повторно. Промежуточные пиксели
нужны только до готовности общего результата. Фон использует существующие
ограничения и повторы; готовые объекты закрыты. Публичная выдача остаётся B22.
