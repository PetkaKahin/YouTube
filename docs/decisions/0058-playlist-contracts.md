# ADR-0058: поля и курсорная пагинация плейлистов

Статус: принято пользователем; Q44 и Q08 для плейлистов закрыты.

Название — 1–100 символов после удаления крайних пробелов, описание —
до 5000 символов с переносами. Списки плейлистов и их содержимое — cursor по 20.
Список владельца показывает новые плейлисты первыми; видео внутри идут
по добавлению, новое — в конец. Ручная перестановка не вводится.

Режимы public/unlisted/private, независимые права видео и выбор любого числа
своих плейлистов сохраняются по ADR-0010/0011. Повтор выбора не меняет позицию
или даты; удаление и повторное включение добавляет видео в конец.
Контракт реализации — [плейлисты](../backend/playlists.md).
