# ADR-0060: порядок email-разрешений

Статус: принято пользователем; Q08 для списка разрешений закрыт.

Owner-список email-разрешений использует общий cursor по 20 из ADR-0059.
Новые разрешения показываются сверху, повторное сохранение того же состояния
не меняет позицию. Отзыв удаляет разрешение; последующая новая выдача получает
новую позицию сверху. Количество разрешений не ограничивается размером страницы.

Курсор не содержит адресов: только числовую границу и контекст владельца/видео.
Авторизация владельца проверяется на каждом запросе. Порядок старых записей,
для которых момент выдачи неизвестен, миграция сохраняет алфавитным;
после миграции новые выдачи идут выше этого набора.

Контракт и проверки — [приватный доступ](../backend/private-access.md).
