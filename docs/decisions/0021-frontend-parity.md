# ADR-0021: соответствие внешнему виду и поведению YouTube

Статус: принято пользователем 2026-11-12. Уточняет требование UI из
[ADR-0001](0001-foundation.md), не расширяет продуктовый объём.

## Решение и последствия

Для экранов и действий нашего ТЗ копируется не только внешний вид, но и
наблюдаемое поведение YouTube. Простота реализации бэкенда не оправдывает
упрощение видимых взаимодействий. Поддерживаются ПК и мобильный веб в тёмной теме.

При разработке поэкранно закрепляются референсы и состояния взаимодействия.
Явные отличия бизнес-правил проекта сохраняются; функции вне ТЗ не добавляются.
Служебная модерация требует согласованной адаптации, а не заявления о копии
неизвестного внутреннего UI YouTube. Критерии хранятся в
[документе соответствия](../frontend/youtube-parity.md), работы —
[реестре F01–F33](../tasks/frontend/README.md).

На момент записи подготовлены требования, без реализации экранов,
собранных референсов и пройденной визуальной приёмки. Q07 остаётся открытым
по конкретным референсам/браузерам/размерам и деталям зависимой реализации.
