# ADR-0037: название и описание видео

Статус: принято пользователем 2026-11-13; Q37 закрыт.

## Решение

Название обязательно уже при создании черновика: 1–100 символов после удаления
пробельных символов по краям. Описание необязательное, до 5000 символов;
это обычный текст, переносы строк сохраняются. Правила действуют также
при изменении настроек. Приватность выбирается явно: public или private.

## Последствия

Домен проверяет длины, PostgreSQL дублирует ограничения длины и состояний.
Клиент не задаёт владельца, даты или служебные состояния. Описательный текст
не выполняется как SQL/HTML; API возвращает JSON, отображение на фронтенде
должно использовать текстовый вывод. NUL и некорректные Unicode surrogate
отклоняются как непредставимые в PostgreSQL UTF-8, без эха входных значений.
Удаление крайних пробелов названия не считается реальной правкой,
если нормализованное значение совпало с сохранённым.
