# ADR-0063: SCSS и границы визуального соответствия

Статус: принято пользователем 2026-11-16.

## Решение

Основной интерфейс копирует YouTube в пределах ТЗ и согласованных референсов
по [ADR-0021](0021-frontend-parity.md). Формы входа и регистрации пользователь
разрешил оформить самостоятельно: их поля и поведение должны следовать ТЗ,
копирование Google-входа не требуется.

Приняты собственные Vue-компоненты без UI-библиотеки, SCSS и токены тёмной темы.
Язык — русский. Допуск геометрии при визуальном сравнении — до 2 CSS px;
цвета и состояния проверяются отдельно. Поддерживаются обычные браузеры,
ограничение одним движком не вводится. Конкретные минимальные версии не заданы.

## Последствия

Референсы и недостающие публичные состояния изучаются самостоятельно через
GET и работающую страницу. У пользователя запрашиваются дополнительные
материалы, если этого недостаточно. Замазанная личная информация для оболочки
и главной не нужна. Источники и размеры — в [каталоге](../frontend/references.md).

Разрешение свободно оформить авторизацию не отменяет сходства основных экранов
и не расширяет набор функций ТЗ. Плеер и другие ещё не выбранные зависимости
согласуются перед соответствующей реализацией.
