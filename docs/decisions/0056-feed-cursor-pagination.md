# ADR-0056: курсорная пагинация главной ленты

Статус: принято пользователем; закрывает Q08 для главной B23.

## Решение

Главная возвращает порции по 20 видео и курсор следующей порции.
Порядок — added_at DESC, id DESC: одинаковые даты имеют устойчивый порядок.
added_at означает успешное завершение передачи исходника по ADR-0012.
Перед пагинацией применяются публичность, публикация, отсутствие скрытия и
фактическая готовность хотя бы одного целого видеоварианта.

Курсор кодирует границу сортировки, не предоставляет прав и не фиксирует
исторический снимок ленты. Каждый запрос заново читает актуальные состояния;
появившиеся выше границы видео видны при обновлении первой порции. Переход
в private/hidden закрывает последующие запросы к карточке и её медиа.

Новых библиотек, секретов, кэша или числовых лимитов остальных списков нет.
Пагинация поиска, комментариев и других списков остаётся в Q08.
Контракт и проверки — [главная лента](../backend/feed.md).
