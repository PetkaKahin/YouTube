# ADR-0015: длина и порядок комментариев

Статус: принято пользователем. Дата: 2026-11-12.
Уточняет R02 и часть Q08 о комментариях; включает последующее закрытие Q18.

## Контекст

Для комментариев требовалось определить лимит и порядок показа.
Пользователь подтвердил 2000 символов и добавил сортировку по числу лайков.

## Решение

Длина — не более 2000 символов. По умолчанию новые комментарии первыми;
дополнительный порядок — от большего числа лайков к меньшему.
При равенстве числа лайков более новые комментарии показываются выше.
Вошедший пользователь с доступом к видео может поставить один лайк любому
доступному комментарию и снять его.
Канонические правила — в [Comment](../backend/modules/comment.md).

## Последствия

Для сортировки нужны реальные данные лайков комментариев. В объём R02
входит этот показатель; прежнее исключение любых реакций уточнено для лайков.
Права на комментарии сохраняются при любой сортировке.
Q18 закрыт: право на лайк, его отмена и порядок при равенстве счётчиков
согласованы. Пагинация и UI отложены до соответствующих этапов.
