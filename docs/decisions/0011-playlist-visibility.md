# ADR-0011: три режима видимости плейлиста

Статус: принято пользователем. Дата: 2026-11-12.
Заменяет часть [ADR-0010](0010-playlist-creation.md) о видимости плейлистов
и их доступе по email. Остальные решения о создании и порядке сохраняются.

## Контекст

Пользователь уточнил требуемое поведение плейлистов: отменил выдачу доступа
по email и выбрал публичный, по ссылке и ограниченный доступ только владельцу.

## Решение

- `public` — публичный плейлист, доступен всем и показан на канале.
- `unlisted` — доступ любому со ссылкой, в том числе гостю; в публичном списке
  канала не показывается.
- `private` — доступ только вошедшему владельцу, известная ссылка не открывает
  плейлист другим пользователям.

У плейлиста нет разрешений по email. Канонические правила — в
[Channel](../backend/modules/channel.md).

## Последствия

Это изменение касается плейлистов. Приватные видео по-прежнему открываются
владельцу и разрешённым email; режима unlisted для самих видео нет.
Открытие плейлиста по ссылке не открывает приватные видео внутри него.
Метаданные и медиапоток каждого видео подчиняются его собственным правам.

UI обсуждается на этапе разработки. [Открытые вопросы](../tasks/open-questions.md).
Реализация ещё не начата.
