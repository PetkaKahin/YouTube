# ADR-0068: приблизительное сходство Studio и параметры видео

Статус: принято пользователем 2026-11-16. Уточняет ADR-0063/0066/0067.

## Визуальные границы

Пользователь уточнил: Studio необязательно копировать «1 в 1», достаточно общего
сходства с YouTube Studio. Это относится к созданию/редактированию контента,
включая уже реализованные таблицу плейлистов и загрузку. Можно самостоятельно
выбирать компоновку и состояния в известном визуальном стиле Studio в пределах ТЗ;
отсутствие точного снимка каждого элемента Studio само по себе не блокирует вёрстку.
Публичный интерфейс сохраняет прежние требования соответствия YouTube.

Согласованы SCSS, тёмная тема, обычные браузеры и доступность. Допуск 2 CSS px
из ADR-0063 остаётся критерием публичных экранов; Studio оценивается по общему
сходству и рабочим сценариям. Свобода компоновки не добавляет функций вне ТЗ.

## Параметры видео

Переданы снимки значка видео, общей таблицы плейлистов с действиями при наведении
и модалки «Кому вы хотите открыть доступ к видео?» — [каталог](../frontend/references.md#параметры-видео-studio).
В общей таблице плейлистов галочки не вводятся. Привязка видео к плейлистам
сохраняет согласованный F28 множественный выбор: это отдельный элемент формы видео.
Действия редактирования/аналитики плейлиста из снимка не расширяют ТЗ.

Превью позволяет выбрать готовый серверный кадр или передать своё изображение
по прежним правилам Q42/Q43. Для разрешений используется модалка с адресами email;
Google OAuth, уведомления по почте и поиск аккаунтов не добавляются.

Выбор до создания видео хранится локально. После подтверждения исходника и до
публикации сервер применяет плейлисты, разрешения и передачу своего превью.
Ошибка не выдаётся за успешную публикацию; подтверждённые частичные изменения
не откатываются фиктивно, повтор продолжает оставшиеся действия.
После создания видео эти элементы могут менять свои данные самостоятельно.
