# ADR-0004: сессии и назначение ролей

Статус: принято пользователем. Дата: 2026-11-11.
Уточняет оставшуюся часть Q01 после [ADR-0002](0002-registration.md).

## Контекст

Вход использует серверную сессию в Valkey. Требуется определить её срок
и порядок назначения ролей в рамках существующего ТЗ.

## Решение

Сессия действует 30 дней без активности и продлевается при использовании.
После истечения срока необходим новый вход.

При регистрации каждый аккаунт получает роль пользователя. Назначение ролей,
включая первого администратора, выполняется CLI-командами по email уже
зарегистрированного пользователя внутри Docker. UI назначения ролей пока нет.
Канонические правила находятся в [User](../backend/modules/user.md).

## Последствия

Серверный срок сессии и срок cookie согласованно продлеваются; потеря Valkey
по-прежнему допускает разлогинивание. CLI управления ролями нужна в prod,
а изменение роли должно учитываться существующими сессиями.
Первый зарегистрированный аккаунт не получает привилегий автоматически.

На момент принятия Q01 оставался открытым по валидации имени/email/пароля.
Позднее эта часть согласована в [ADR-0005](0005-registration-validation.md), Q01 закрыт.
