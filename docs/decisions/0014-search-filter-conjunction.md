# ADR-0014: одновременное выполнение фильтров

Статус: принято пользователем. Дата: 2026-11-12.
Заменяет первоначальное уточнение в [ADR-0013](0013-search-filters.md)
о достаточности одного признака.

## Контекст

При разборе примера «Сегодня + 4K» пользователь пересмотрел правило объединения
и явно потребовал совпадения со всеми фильтрами, в том числе внутри особенностей.

## Решение

Все заданные применимые условия объединяются через «И». Сочетание 4K + HDR
требует обоих признаков, сочетание с датой также требует нужного периода.
Отсутствующий фильтр не ограничивает выдачу. Права доступа и совпадение текста
остаются обязательными. Канонические правила — в [поиске](../project/search.md).
При последующем уточнении пользователь подтвердил: сочетание 4K + HDR
требует готовой версии именно 2160p HDR. Отдельных 2160p SDR и 720p HDR
недостаточно. Даты создания каналов и плейлистов соответствуют созданию
этих объектов; ранее выбранная дата видео — завершение загрузки — сохраняется.

## Последствия

Нельзя расширять выдачу результатами, подходящими только по части выбранных
условий. Проверки должны включать объекты, не подходящие ровно по одному
условию, и исключать их из результатов.
Q16 закрыт: даты создания объектов и совместимость признаков готового
варианта также согласованы. Детали UI и технические параметры отложены.
