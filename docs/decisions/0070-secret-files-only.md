# ADR-0070: секреты только в docker/secrets

Статус: принято пользователем 2026-11-18. Отменяет локальную копию пароля
из [ADR-0069](0069-development-database-and-initial-schema.md) и восстанавливает
единое правило [ADR-0019](0019-compose-secrets.md).

Все секреты конфигурации хранятся в игнорируемом каталоге `docker/secrets/`.
Для IDE пароль PostgreSQL берётся из `docker/secrets/postgres_password`;
в `.env` остаются только имя БД, пользователь, порт и прочие несекретные настройки.
`make init` удаляет прежнюю копию пароля из `.env`, сохраняя значение secret-файла.
Передача сервисам остаётся через Compose Secrets и `/run/secrets/`.
Порт dev и начальная схема из ADR-0069 сохраняются.
