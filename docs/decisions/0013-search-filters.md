# ADR-0013: типы и фильтры поиска

Статус: принято пользователем. Дата: 2026-11-12.
Первоначальное уточнение о совпадении хотя бы по одному признаку заменено
[ADR-0014](0014-search-filter-conjunction.md): требуется выполнение всех условий.
Расширяет R04 и уточняет Q08 после [ADR-0012](0012-feed-and-search-order.md).

## Контекст

Пользователь уточнил набор возможностей поиска вместо предложенных сортировок
по просмотрам и релевантности. Выбранный список включает новые типы результатов
и признаки, которых не было в первоначальном поиске только по названию видео.

## Решение

Поддерживаются видео, каналы и плейлисты. Фильтры: три диапазона длительности,
четыре периода загрузки, особенности 4K/HD/субтитры/HDR.
Сортировки — по дате создания и по дате изменения, по умолчанию первая,
новые сначала. Полный канонический список — в [поиске](../project/search.md).

При дальнейшем разборе пользователь подтвердил: дата изменения обновляется
только после правок владельца. Просмотры, лайки и фоновая обработка на неё
не влияют. Для первой версии субтитры берутся только из уже имеющихся
дорожек загруженного видеофайла.
Также согласованы признаки готовности: HD — качество от 720p, 4K — 2160p,
HDR — готовая доступная зрителю HDR-версия. Пока результат обрабатывается,
видео не удовлетворяет соответствующему фильтру.
Поля совпадения также согласованы: для канала имя или `@тег`, для плейлиста
название; везде по части текста без учёта регистра. Длительность и особенности
относятся только к результатам-видео, не к каналам и плейлистам.
Периоды календарные по московскому времени: день с 00:00, неделя с понедельника,
месяц с первого числа, год с 1 января. Действующая логика сочетания фильтров —
«И» по всем заданным условиям, включая особенности; [ADR-0014](0014-search-filter-conjunction.md).

## Последствия

Поиск затрагивает данные Video и Channel; видимость каждого результата
продолжает проверяться. Подготовка субтитров становится частью конвейера,
отдельная загрузка субтитров и автогенерация не входят в первую версию.
Q16 и Q17 закрыты: фильтры, даты, источник субтитров и смысл HDR определены.
Для 4K + HDR требуется готовый 2160p HDR, признаки не собираются из разных
качеств. Профили кодирования и форматы субтитров отложены до технического этапа Q03.

Детали UI и технические средства отложены.
