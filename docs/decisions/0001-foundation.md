# ADR-0001: основа проекта

Статус: принято пользователем. Дата: 2026-11-11.

## Контекст

Нужна учебная копия YouTube для ПК и мобильного веба. Приоритет — полноценная
работа с видео, близкий интерфейс заданных экранов и экономная документация,
позволяющая продолжать работу без повторного исследования всей кодовой базы.
Пользователь отдельно ограничил функциональность исходным ТЗ.

## Решения

- Объём ограничен [ТЗ](../project/requirements.md), заимствуются только нужные
  этим сценариям бизнес-правила YouTube.
- Бэкенд — Python/FastAPI, модульный монолит; крупные бизнес-модули общаются
  через `public`, внутри clean architecture. [Архитектура](../backend/architecture.md).
- Постоянные данные — PostgreSQL; потеряемые кэш и сессии — Valkey;
  файлы — RustFS. Остальной утверждённый стек — [бэкенд](../backend/README.md).
- Обработка сразу проектируется фоновой, с FFmpeg и HLS, качествами
  от 360p до 4K в пределах исходника. [Конвейер](../backend/video-pipeline.md).
- Фронтенд — утверждённый Vue/TypeScript-стек и FSD; ПК и мобильный веб,
  пока только тёмная тема с возможностью расширения. [Фронтенд](../frontend/README.md).
- Весь цикл приложения — Docker; `dev` и `prod` наследуются от `base`.
  Требуется деплой одной командой на чистую Ubuntu. [Инфраструктура](../infrastructure/docker.md).
- Три скилла: бэкенд, фронтенд и документация. В каждом обязательное правило:
  неразрешённые вопросы сначала задаются пользователю, зависимая работа — после ответа.

## Последствия

Архитектурные границы нужно проверять, фоновые задания должны переживать
потерю Valkey, приватность распространяется на файлы HLS, а не только API.
Серверный контракт связывает FastAPI с генерацией клиента Hey API.
Тёмная тема строится на токенах; возможность расширения не означает реализацию
дополнительных тем сейчас. Новые функции не следуют автоматически из сходства с YouTube.

## Что этим ADR не выбрано

Этот ADR не выбирает ORM, миграции, библиотеку заданий, способ входа, кодеки,
медиашлюз, версии зависимостей и целевую Ubuntu. Последующие решения:
[ADR-0002 — вход и регистрация](0002-registration.md).
Актуальные нерешённые параметры — в [открытых вопросах](../tasks/open-questions.md).
Базовая декомпозиция и поведение из проектных документов не означают наличие кода.
Позднее пользователь явно добавил создание плейлистов и настройки видео в ЛК;
[расширение R16: ADR-0010](0010-playlist-creation.md).
