ADR сохраняет контекст, выбор и последствия. Стек и детальные правила находятся
в профильных документах; здесь на них ссылки. Открытые предложения не получают
статус принятого решения. Изменение принятого выбора оформляется новым ADR
со ссылкой на заменяемый; мелкая редактура не требует отдельной записи.
