# Поиск: бизнес-правила

Статус: бизнес-правила поиска согласованы пользователем 2026-11-12, Q16/Q17 закрыты.
[ADR-0013](../decisions/0013-search-filters.md), [сочетание фильтров](../decisions/0014-search-filter-conjunction.md).
Документ описывает поведение, расположение элементов UI определяется позже.

## Область поиска и доступ

Поиск поддерживает видео, каналы и плейлисты. Во всех случаях используется
совпадение по части текста без учёта регистра:

| Тип результата | Поля совпадения |
| --- | --- |
| Видео | Название |
| Канал | Отображаемое имя или `@тег` |
| Плейлист | Название |

Email аккаунта не является публичным поисковым полем. Описания объектов
и текст субтитров в совпадении не участвуют.

В результаты видео попадают только публичные опубликованные нескрытые видео
с готовым качеством. Из плейлистов в общем поиске доступны только `public`;
`private` и `unlisted` не обнаруживаются через поиск. Открытие плейлиста
не отменяет права на каждое входящее видео.
Источники правил: [Video](../backend/modules/video.md), [Channel](../backend/modules/channel.md).

## Утверждённые фильтры

| Группа | Варианты |
| --- | --- |
| Тип | Видео; каналы; плейлисты |
| Длительность | Менее 3 минут; 3–20 минут; более 20 минут |
| По дате загрузки | Сегодня; за эту неделю; за этот месяц; за этот год |
| Особенности | 4K; HD; субтитры; HDR |

Длительность и особенности применяются только к видео. Каналы и плейлисты
по этим признакам не фильтруются; длительность или качества содержащихся
в них видео не используются как агрегированные признаки канала/плейлиста.

Границы длительности не пересекаются: ровно 3 и ровно 20 минут входят
в среднюю группу. Список особенностей определяет нужные признаки результата,
но не выбирает кодеки или профиль обработки. Субтитры берутся только из
дорожек загруженного видео; [правила подготовки](../backend/video-pipeline.md).

Утверждённые критерии особенностей:

| Признак | Когда видео ему соответствует |
| --- | --- |
| HD | Есть готовое доступное зрителю качество 720p или выше |
| 4K | Есть готовое доступное зрителю качество 2160p |
| Субтитры | Для просмотра подготовлены дорожки из исходного видео |
| HDR | Есть готовая доступная зрителю HDR-версия |

Пока нужное качество обрабатывается, видео не попадает под соответствующий
фильтр. Разрешение исходника или его HDR-признак сами по себе не означают готовность
такой версии для зрителя. Видео с готовым 4K также удовлетворяет HD.
Появление нового готового качества не меняет дату изменения видео.

## Сочетание условий

Все заданные условия, применимые к типу результата, выполняются одновременно:
между группами и внутри особенностей действует **«И»**.
Правило «достаточно одного признака» отменено пользователем;
[ADR-0014](../decisions/0014-search-filter-conjunction.md).

Тип, длительность и период — по одному значению в группе; особенностей может
быть несколько. Не заданный фильтр не ограничивает результаты. Поисковый текст
и обязательные проверки доступа также сохраняются.

Например, «Сегодня + 4K + HDR» требует одновременно нужной даты и обоих
признаков. Старое 4K HDR и сегодняшнее видео без HDR не подходят.
Для сочетания 4K/HDR нужен один готовый вариант **2160p HDR**. Отдельные
готовые 2160p SDR и 720p HDR вместе этому сочетанию не соответствуют.
Все особенности должны быть совместно доступны в выбранном варианте просмотра;
это не требует хранить видео и субтитры в одном физическом файле.

## Календарные периоды

Все периоды считаются по московскому времени (`Europe/Moscow`), от начала
текущего календарного периода до текущего момента:

| Период | Начало |
| --- | --- |
| Сегодня | 00:00 текущего дня |
| За эту неделю | 00:00 понедельника текущей недели |
| За этот месяц | 00:00 первого числа текущего месяца |
| За этот год | 00:00 1 января текущего года |

## Сортировка и даты

| Режим | Порядок |
| --- | --- |
| По дате создания | Новые сначала; режим по умолчанию |
| По дате изменения | Последние изменённые сначала |

Дата создания определяется моментом создания соответствующего объекта:

| Тип | Событие для даты создания/добавления |
| --- | --- |
| Видео | Успешное завершение загрузки исходного файла, согласовано в Q15 |
| Канал | Создание канала при регистрации пользователя |
| Плейлист | Создание плейлиста |

Для видео поздняя публикация или готовность следующего качества не меняют
дату добавления; дата создания черновика её не заменяет.

Дата изменения отражает только фактические правки владельца: название,
описание, видимость, настройки доступа, состав плейлиста. Просмотры, лайки,
подписки и фоновая обработка её не меняют. Сохранение без изменения данных
не должно поднимать объект в выдаче по дате изменения.

Сортировки по просмотрам, лайкам или релевантности не выбраны: действующий
набор состоит из двух перечисленных режимов. Сортировка и фильтры применяются
к разрешённым результатам и не обходят ограничения видимости.
