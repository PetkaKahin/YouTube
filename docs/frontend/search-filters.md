# Фильтры и сортировки поиска

F11 — `done` по функциональному профилю. Реализация обновлена по ответам
пользователя и проверена через реальный API. Бизнес-правила — [поиск](../project/search.md),
HTTP-контракт — [B24/B25](../backend/search.md). Внешний вид проверяет пользователь.

## Применение и представление

Решение пользователя от 2026-11-17: на ПК выбор сразу применяется и закрывает
панель, на телефоне фильтры находятся в прокручиваемой модалке. Выбор внутри
модалки также применяется сразу с закрытием. Для последовательного выбора
нескольких особенностей панель/модалку открывают повторно; выбор берётся из URL.

`type`, `duration`, `period` содержат одно значение, повторный выбор снимает
ограничение. `feature` допускает несколько значений, снятие одного сохраняет
остальные. `sort` всегда имеет смысл: created по умолчанию, updated — по изменению.
Снятие явного created убирает sort из URL, сохраняя сортировку created.
Правила «И», МСК и границы 3/20 минут выполняет сервер; браузер не фильтрует
уже загруженные карточки и не вычисляет готовность по исходнику.

ПК использует раскрываемую секцию; Escape закрывает её с возвратом фокуса,
нажатие вне секции закрывает без перехвата фокуса выбранного элемента. Телефон
использует существующий native dialog: фокус удерживается внутри, фон не
прокручивается, длинное содержимое прокручивается. Крестик/Escape возвращают
фокус кнопке «Фильтры». Навигация и смена размера/сессии закрывают представление
и освобождают прокрутку. Эти действия не добавляют отдельную кнопку применения.

## URL и состояние

[Модель](../../frontend/src/pages/search/model/filters.ts) содержит согласованный
набор и читает параметры URL. Значения проверяются до запроса: неизвестное,
пустое значение или повтор одиночной группы показывают ошибку с рабочим сбросом,
не превращаясь в более широкую выдачу. Повтор одинаковой особенности
нормализуется в один параметр; разные особенности передаются отдельными feature.
Параметры не вставляются в HTML, путь или текст ошибки.

[SearchPage](../../frontend/src/pages/search/ui/SearchPage.vue) меняет URL,
сбрасывает cursor и получает первую страницу нового ключа Query. Все следующие
страницы сохраняют ограничения. История и обновление восстанавливают выбранные
состояния, запоздалый ответ старого ключа не заменяет выдачу.
Состояния ошибок не выдают неуспешный запрос за применение без фильтра.
[SearchFilters](../../frontend/src/pages/search/ui/SearchFilters.vue) рисует один
набор для ПК и телефона; серверное состояние остаётся в Query, открытие — локально.

## Проверки

Профиль [filters.mjs](../../docker/browser/filters.mjs) использует реальный
изолированный API/PostgreSQL/Nginx/RustFS и fixture `--media --channel`.
В Chromium и Firefox прошли по **50 функциональных проверок**.
В Docker прошли vue-tsc/Vite build, ESLint и Prettier затронутого фронтенда.
После изменений F11 повторён непосредственно затронутый профиль F10:
по 39 проверок в Chromium и Firefox прошли.
Профиль сравнивает все страницы с отдельным чтением API для длительностей, периодов,
особенностей, сочетаний и сортировок. Для HD/субтитров готовые материалы
дают разные наборы, поэтому проверка отличает «И» от «ИЛИ». Полный набор
параметров с повторяемыми feature проверяется также на cursor-страницах
плейлистов, к которым видео-ограничения по ТЗ не применяются. Старое видео действительно меняется
владельцем через Cookie/CSRF, чтобы порядок updated отличался от created.
Смена даты обработки или искусственные ready/HDR-ответы не подставляются.

Проверяются закрытие/фокус, серверная пагинация с полным набором ограничений,
Back/Forward/reload, одиночные и множественные значения, повреждённый URL,
сброс/повтор после ошибки, поздний ответ, мобильная модалка, Tab/Escape,
прокрутка и освобождение фона. Ошибку/задержку вводит только HTTP-прокси.
Функциональная проверка прокрутки не является сверкой геометрии; скриншотов нет.

Проверки реальных 2160p HDR-профилей, календарных границ и ровно 180/1200 секунд
принадлежат B25: на фронте проверяется передача enum/сочетаний и совпадение
с его ответом на готовых скачанных материалах. Safari и реальная экранная
клавиатура не проверяются этим профилем. Общий набор приложения не запускался: это профиль F11 и изменённой интеграции F10.
