# Референсы интерфейса

Статус F01: `in_progress`. Собраны референсы оболочки и главной;
согласованы UI-подход и допуск сравнения. Формы авторизации делегированы исполнителю
по [ADR-0063](../decisions/0063-frontend-ui-and-reference-scope.md).
Критерии сравнения и границы функций — [соответствие YouTube](youtube-parity.md).

## Принято пользователем 2026-11-16

- Язык интерфейса — русский.
- Источник — снимки YouTube пользователя в `frontend/Reference/`.
  По предложению пользователя недостающие публичные состояния также изучаются
  через GET и работающую страницу в браузере. Дополнительные снимки или сохранённые
  страницы запрашиваются, если самостоятельного доступа недостаточно.
- Поддержка браузеров — «все», с использованием обычных веб-возможностей
  без экзотики. Ограничение одним браузером не принято; конкретные минимальные
  версии не задавались.
- Личная информация на снимках замазана. Для оболочки и главной раскрывать её
  не требуется; замазанные области не служат эталоном текста и изображений.
- UI — собственные Vue-компоненты без UI-библиотеки; стили — SCSS,
  цвета и размеры — в токенах тёмной темы. Подключён Dart Sass 1.108.2.
- Допуск геометрии публичных экранов при визуальном сравнении — до 2 CSS px.
  Для Studio пользователь затем разрешил приблизительное сходство — ADR-0068.
  Цвета и состояния сравниваются отдельно.

## Формы входа и регистрации

Пользователь разрешил любые формы по ТЗ; основное требование копирования YouTube
сохраняется для основного интерфейса. Отдельное согласование макета авторизации
не требуется — [ADR-0063](../decisions/0063-frontend-ui-and-reference-scope.md).

Реализованы отдельные страницы без боковой навигации.
Сверху — логотип с переходом на главную; форма на ПК расположена по центру
и имеет максимальную ширину 480 CSS px, на телефоне занимает доступную ширину
с отступами 16 CSS px. Поля идут одной колонкой; оформление использует тёмную
тему, типографику и элементы YouTube. Вход содержит email и пароль, регистрация —
поля ТЗ в порядке имя, email, тег, пароль, повтор пароля. Между формами есть
ссылки перехода. Проверки и ограничения — [реализация](implementation.md).
