# Фронтенд

Статус: утверждённый стек и целевая спецификация; приложения пока нет.

| Компонент | Назначение |
| --- | --- |
| Vue 3 + TypeScript + Vite | SPA, типизация и сборка |
| Vue Router | Маршруты перечисленных в ТЗ экранов |
| Pinia | Клиентское состояние |
| Hey API | Генерируемые из OpenAPI клиент и типы |
| TanStack Query для Vue | Запросы, серверный кэш и мутации |
| vue-tsc | Проверка типов TypeScript и Vue |
| ESLint | Статические проверки |
| Prettier | Форматирование |

Архитектура — FSD. Поддержка — ПК и мобильный веб, тёмная тема.
Пакетный менеджер, версии и библиотека HLS-плеера пока не выбраны.

После реализации контейнеров необходимы vue-tsc, ESLint, Prettier и production
build в Docker. Для поведения нужны проверки просмотра HLS, сессии, приватности,
загрузки и адаптивности. Средство браузерного тестирования ещё не выбрано;
конкретные команды будут добавлены после настройки, сейчас их нет.
