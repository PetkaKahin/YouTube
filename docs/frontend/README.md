# Фронтенд

Завершена [итоговая функциональная приёмка](final-acceptance.md) F01–F04.
Общий прогон выполнен: открыты два замечания бэкенда и аудит npm/picomatch.

Статус: реализованы регистрация, вход/выход, оболочка, главная, поиск,
просмотр, публичный канал, состав плейлиста и создание/личный список
плейлистов Studio, загрузка/обработка/публикация, раздельные списки своих видео
и черновиков, общие настройки видео и параметры превью/плейлистов/email,
жалобы и служебная очередь с просмотром и решениями, история ошибок
и три режима повтора заданий для администратора. Подключены личные история,
понравившиеся, плейлисты, лента подписок и раскрытие каналов sidebar — [R19](library.md).
Страница просмотра дополнена правой лентой, подсветкой и сохранением в плейлист —
[R20](watch-enhancements.md). Уточнения хедера/dropdown/автозапуска и дизлайк
[R21](watch-refinements.md) подключены; меню плеера поднято над шкалой времени.
SCSS, Hey API, Query и Pinia подключены.
Общая функциональная приёмка интерфейса пройдена; результат итогового прогона
и ограничения — [приёмка](final-acceptance.md), [реализация](implementation.md).

| Компонент | Назначение |
| --- | --- |
| Vue 3 + TypeScript + Vite | SPA, типизация и сборка |
| Vue Router | Маршруты перечисленных в ТЗ экранов |
| Pinia | Клиентское состояние |
| Hey API | Генерируемые из OpenAPI клиент и типы |
| TanStack Query для Vue | Запросы, серверный кэш и мутации |
| vue-tsc | Проверка типов TypeScript и Vue |
| ESLint | Статические проверки |
| Prettier | Форматирование |
| Dart Sass | Компиляция SCSS |
| lossless-json | Точная передача int64-идентификаторов через JSON |
| hls.js | HLS-поток и дорожки под собственными Vue/SCSS-контролами |

Архитектура — FSD. Поддержка — ПК и мобильный веб, тёмная тема.
Создание/редактирование своего контента размещается в отдельной Studio;
быстрое создание плейлиста с текущим видео также доступно из закладки
[обычного просмотра R20](watch-enhancements.md). Обычный собственный канал выглядит как чужой —
[ADR-0066](../decisions/0066-studio-playlist-interface.md). F21 завершён по
[функциональному профилю Studio](studio.md).
Публичный UI и наблюдаемое поведение должны повторять YouTube 1 в 1 в рамках ТЗ;
для Studio пользователь разрешил общее сходство —
[ADR-0068](../decisions/0068-studio-visual-scope-and-video-options.md). Критерии и согласованные
отличия — [соответствие YouTube](youtube-parity.md).
Пакетный менеджер — npm. Версии закреплены в
[package.json](../../frontend/package.json) и [Docker](../infrastructure/docker.md).
Приняты собственные Vue-компоненты и SCSS без UI-библиотеки;
установлен Dart Sass 1.108.2. Для плеера выбран `hls.js` 1.7.4 с собственными
Vue/SCSS-контролами — [ADR-0065](../decisions/0065-hls-client.md).
Библиотека подключена; контракты автора видео Q48 и канала плейлиста Q49
обновлены на бэкенде и получены генерацией. Прямой плейлист открывается на канале.
`OPENAPI_URL` задаётся в корневом `.env` и передаётся Node через Compose
для Hey API; это внутренний адрес, не URL для браузера. Секреты хранилищ
Node не получает; браузер использует `/api` того же origin без переменных окружения.

Приёмка фронтенда включает безопасность браузерных сценариев: пользовательский
текст, cookie/CSRF, отсутствие секретов в сборке и персональных данных прошлого
пользователя в интерфейсе/кэше. Одного визуального совпадения недостаточно.

Профильные проверки после запуска dev: `./docker/run dev exec node npm run lint`, `npm run format:check`,
`npm run typecheck`, `npm run build`, `npm test` с тем же Docker-префиксом.
Полный `./docker/run check` запускается после завершения выполняемого плана
по [проектному скиллу](../../skills/frontend/SKILL.md#проверки).
`npm run api:generate` запускает Hey API из OpenAPI внутри контейнера.
Клиент сгенерирован из текущего OpenAPI. Для браузерных проверок добавлены
Chromium/CDP и Firefox/BiDi в Docker; сценарии и актуальные результаты —
в [описании реализации](implementation.md). Точные int64-идентификаторы подключены
по [ADR-0064](../decisions/0064-exact-client-identifiers.md), Q47 закрыт.
