# Открытые вопросы

Это не запрос реализовать дополнительные функции. Здесь перечислены только
параметры, нужные для реализации текущего ТЗ. Вопросы задаются пользователю
перед зависимой задачей, после проверки уже имеющихся ответов.
Само наличие записи в списке не блокирует другие задачи. После отправки вопроса
пользователю вся работа над текущей задачей останавливается до ответа, включая
независимые части и проверки. Таймаут, молчание и предположение не заменяют ответ.
Разбор идёт небольшими связанными порциями. Ответы могут порождать новые
вопросы: они тоже фиксируются здесь и прорабатываются с пользователем.

**Docker-этап завершён; подготовлены бизнес-задачи бэкенда и фронтенда.** Бизнес-правила
текущего разбора согласованы. Выбор инструментов —
[ADR-0020](../decisions/0020-backend-libraries.md), описания и требования —
[B01–B36](backend/README.md), [F01–F33](frontend/README.md).
Для фронтенда принято соответствие UI и видимого поведения YouTube в пределах ТЗ;
[критерии](../frontend/youtube-parity.md). Новых продуктовых функций декомпозиция не вводит.
Остальные технологии обсуждаются перед зависимой реализацией.
Детали UI отложены до разработки интерфейса; их согласованные требования сохраняются.

## Уже решено — не спрашивать повторно

PostgreSQL выбран. Видео сразу обрабатываются FFmpeg в фоне, раздаются HLS,
лестница 360p–4K зависит от исходника. Фронтенд — FSD, ПК и мобильный веб,
сейчас только тёмная тема. Docker: `dev` и `prod` наследуются от `base`.
Функции — ТЗ с явно согласованными дополнениями. Три скилла предназначены для Codex.

Вход — email и пароль. Регистрация — имя, почта, тег, пароль и повтор пароля;
при регистрации автоматически создаётся пустой канал.
Подтверждено пользователем 2026-11-11, [ADR-0002](../decisions/0002-registration.md).
Q01 закрыт. Имя — 2–50 символов; email проверяется стандартно по формату,
без проверки существования ящика; пароль — 6–128 символов без требований
к составу. [ADR-0005](../decisions/0005-registration-validation.md).
Не спрашивать согласованные правила повторно.
Q11 закрыт: тег уникален без учёта регистра, формат согласован; имя может
повторяться и показывается как название канала и имя автора комментариев.

Сессия действует 30 дней без активности, при использовании срок продлевается.
Роли назначаются CLI-командами внутри Docker по email существующего аккаунта,
включая первого администратора. При регистрации всем выдаётся `user`;
UI назначения ролей пока нет. [ADR-0004](../decisions/0004-sessions-and-roles.md).

Очередь заданий хранится в PostgreSQL и не должна теряться. Каждое качество
имеет отдельную задачу и отдельный результат. Для низких качеств снижается
качество и видео, и аудио. [ADR-0006](../decisions/0006-video-jobs-and-audio.md).
Q12 закрыт: у 360p сильно сжимаем звук, у 480p — умеренно, с 720p — обычное
качественное аудио. Видео без звука разрешены. Библиотека очереди не выбрана
и сейчас не обсуждается.

Загрузка ограничена 5 ГБ и 60 минутами, оба предела включительны. Видео ниже
360p разрешены в исходном разрешении без увеличения, с сильным сжатием,
сохраняющим разборчивость. [ADR-0007](../decisions/0007-upload-limits.md).
Входные форматы не ограничены списком расширений: принимается видео, которое
удаётся корректно обработать используемой сборкой FFmpeg. Видеодорожка обязательна,
звуковая — нет. При частичной ошибке готовые качества доступны; если не готово
ни одного, просмотр закрыт, автор видит причину. Бизнес-части Q02 и Q03 закрыты
2026-11-12, [ADR-0008](../decisions/0008-input-formats-and-failures.md).

Q04 закрыт: доступ к приватному видео выдаётся по любому корректному email.
Наличие аккаунта по введённому адресу не раскрывается; разрешение можно добавить
до регистрации получателя. [ADR-0009](../decisions/0009-private-access-by-email.md).
Q13 закрыт: доверяем email из регистрации, подтверждения почты нет и для
приватного просмотра. Нужен вход в аккаунт с разрешённым email; остальные
правила доступа сохраняются. Это согласованное упрощение учебного проекта.

В Q06 согласовано дополнение R16: пользователь создаёт плейлисты, а в ЛК
в настройках видео выбирает их галочками в выпадающем списке. Видео может
входить в несколько или все свои плейлисты. [ADR-0010](../decisions/0010-playlist-creation.md).
Согласованы обязательное название и необязательное описание, три режима
видимости плейлиста: публичный, по ссылке и приватный (только владельцу).
Выдача доступа к плейлисту по email отменена в [ADR-0011](../decisions/0011-playlist-visibility.md).
Для приватных видео доступ по email сохраняется. Новое видео добавляется в конец,
ручной перестановки нет. Видимость плейлиста не меняет видимость его видео;
разрешения на видео не наследуются от плейлиста. Q14 и бизнес-часть Q06 закрыты.
Место создания и другие детали UI перенесены в Q07 и будут обсуждаться
при разработке интерфейса. Сейчас вопросы об UI не задаются.

В Q08 согласованы главная без алгоритма рекомендаций и порядок по дате
добавления, новые сначала. Поиск по части названия без учёта регистра,
по умолчанию тот же порядок; нужны также дополнительные сортировки,
их набор теперь согласован: по дате создания и изменения.
[ADR-0012](../decisions/0012-feed-and-search-order.md).
Q15 закрыт: дата добавления — завершение загрузки исходника, даже при поздней публикации.
Поиск расширен на видео, каналы и плейлисты, утверждены группы фильтров:
тип, длительность, дата загрузки, особенности. Полный список — в
[правилах поиска](../project/search.md), [ADR-0013](../decisions/0013-search-filters.md).
Уточнения Q16/Q17 согласованы и закрыты.
Согласовано: дата изменения обновляется только при правках владельца,
просмотры/лайки/фоновая обработка её не меняют. Субтитры для первой версии
берутся только из дорожек исходного файла; отдельная загрузка и автогенерация
не включены. [ADR-0013](../decisions/0013-search-filters.md).
Q17 закрыт. HD — готовое качество от 720p, 4K — готовое 2160p, HDR — готовая
доступная зрителю HDR-версия. Пока качество обрабатывается, соответствующий
фильтр его не учитывает. Характеристик исходного файла недостаточно.
Длительность и особенности применяются только к видео, каналы и плейлисты
по ним не фильтруются. Каналы ищутся по имени и `@тегу`, плейлисты — по
названию; во всех случаях по части текста без учёта регистра.
Периоды календарные по МСК: день с 00:00, неделя с понедельника, месяц
с первого числа, год с 1 января. Пользователь пересмотрел правило совпадения:
нужны все заданные условия одновременно, в том числе все выбранные особенности.
Например, 4K + HDR требует обоих признаков. Предыдущее правило «хотя бы один»
отменено; [ADR-0014](../decisions/0014-search-filter-conjunction.md).
Q16 закрыт: канал датируется его созданием при регистрации, плейлист — своим
созданием; для видео сохраняется завершение загрузки. Сочетание 4K + HDR
требует готовой 2160p HDR, отдельные 2160p SDR и 720p HDR его не заменяют.

Для комментариев согласованы лимит 2000 символов и сортировки: новые сначала
по умолчанию, дополнительно — от самых залайканных. [ADR-0015](../decisions/0015-comment-order-and-likes.md).
Q18 закрыт: вошедший пользователь с доступом ставит один лайк любому доступному
комментарию и может снять его; при равенстве числа лайков новые выше.

Согласованы причины жалоб: спам/мошенничество, оскорбления/травля, насилие,
сексуальный контент, авторские права, другое. Для пары «пользователь, видео»
одна запись; повторная отправка обновляет её, в том числе после рассмотрения.
[ADR-0016](../decisions/0016-report-reasons-and-updates.md). Q19 закрыт:
после повторной отправки рассмотренная жалоба снова ожидает модерации,
дубликат записи не создаётся. Само обновление не меняет скрытие видео.

Кэш и серверные сессии находятся в Valkey; физическое устройство браузерной
cookie объяснено в [User](../backend/modules/user.md) и не является выбором
другого хранилища сессий. Дополнительные функции YouTube не требуют обсуждения,
пока пользователь сам не расширит ТЗ.
