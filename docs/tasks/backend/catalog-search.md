# Главная и поиск

B23–B25 — `done`: главная и общий поиск всех трёх типов подключены.
Источники: [Video](../../backend/modules/video.md),
[Channel](../../backend/modules/channel.md), [канонические правила поиска](../../project/search.md),
R01/R04. Общие требования и зависимости — [реестр](README.md).

## B23. Выдавать главную ленту видео

**Результат.** GET `/api/v1/videos/feed`, cursor по 20,
устойчивый added_at/id, публичная готовность до заполнения страницы,
выбранное превью и пакетные публичные данные автора. Контракт, индекс 0016
и проверки — [главная лента](../../backend/feed.md).
Полная регрессия: 982 passed; сквозные dev/prod, штатные проверки качества,
схемы и аудит секретов прошли. Сборки использовали кэш закреплённых пакетов
при внешнем TLS-сбое PyPI; подробности в контракте ленты.

**Описание.** Посетитель получает карточки видео с превью на главной.

**Требования.** Только public, published, visible и хотя бы одно готовое качество.
Порядок — новые сначала по успешному завершению загрузки исходника.
Поздняя публикация/новое качество/лайки не меняют дату добавления.
Главная одинакова по принципу отбора для гостя и вошедшего пользователя,
без алгоритма персональных рекомендаций или отдельной ленты подписок.

**Приёмка.** При одинаковых входных правах исключены private/hidden/черновики/видео
без готовых вариантов. Проверены поздняя публикация старого исходника, готовность
второго качества, отсутствие подходящих видео и отзыв публичного доступа.
Фильтрация доступа действует до подсчётов и разбиения выдачи; кэш не открывает исключённое.

## B24. Искать видео, каналы и плейлисты

**Результат.** GET `/api/v1/search`, буквальная подстрока названия
видео/плейлиста или имени/@тега канала, без учёта регистра. Порции по 20 с курсором,
совместная сортировка, публичные готовые видео и только public-плейлисты,
включая пустые, без персональных полей и чтения содержимого плейлиста.
Контракт и проверки —
[поиск](../../backend/search.md).
Полная регрессия — 1141 passed; статические проверки, dev/prod-квалификация
настоящего HTTP-пути, отказ Valkey и аудит секретов прошли. Обе сортировки
смешивают видео/канал/41 плейлист с равной датой страницами 20/20/3;
старые курсоры сохранены. Private/unlisted не обнаруживаются даже владельцем
или staff; недоступное содержимое не влияет на поиск public-плейлиста.

**Описание.** Посетитель находит доступный объект по части названия или идентичности канала.

**Требования.** Видео ищутся по названию; канал — по имени или `@тегу`;
плейлист — по названию. Совпадение без учёта регистра, по части текста.
Email, описания и текст субтитров не участвуют. Видео соответствуют B23,
плейлисты — только public; private/unlisted не обнаруживаются общим поиском.
По умолчанию новые сначала по дате создания соответствующего объекта.

**Приёмка.** Проверены все три типа, неполное совпадение и другой регистр,
отсутствие результатов, несколько каналов с одинаковым именем и разными тегами.
Разрешённый email не делает private-видео результатом поиска, известная ссылка
не делает unlisted-плейлист обнаружимым. Число результатов и кэш не раскрывают исключённые объекты.

## B25. Сочетать фильтры и сортировки поиска

**Результат.** Для всех трёх типов подключены created/updated,
периоды МСК и фильтры типа; для видео — длительность и сочетания особенностей
по готовым доступным вариантам. Курсор привязан к запросу и фильтрам;
период не сдвигается между страницами после полуночи. Плейлисты фильтруются
по созданию и сортируются по созданию/изменению; duration/feature игнорируются,
включая private-черновики внутри. Фактическая правка состава меняет updated,
no-op сохраняет выдачу — [контракт](../../backend/search.md).

**Описание.** Посетитель уточняет результаты по согласованным признакам.

**Требования.** Тип, длительность и период — по одному значению в группе;
особенностей может быть несколько. Между всеми применимыми условиями — «И».
Незаданный фильтр не ограничивает. Для каналов/плейлистов длительность и особенности
не применяются и не выводятся из содержащихся видео.

Фильтры и их точные границы — в [поиске](../../project/search.md):

- Длительность: менее 3 минут, 3–20 включительно, более 20.
- Периоды: сегодня, текущая неделя с понедельника, месяц, год — от календарного
  начала по Europe/Moscow до текущего момента.
- HD — готовое от 720p, 4K — готовое 2160p, HDR — готовая HDR-версия,
  субтитры — подготовленные из исходника дорожки. 4K + HDR требует готового 2160p HDR.
- Сортировки: по созданию или фактическому изменению владельцем, новые сначала.
  Видео датируется завершением загрузки, канал — созданием при регистрации,
  плейлист — собственным созданием. Изменение от действий зрителей/обработки не учитывается.

**Приёмка.** Проверены границы ровно 3/20 минут и календарные границы МСК,
несколько особенностей и отсутствие одного обязательного признака.
Готовые 2160p SDR + 720p HDR не проходят 4K + HDR; исходник без готовой
нужной версии не проходит признак. Правки владельца меняют соответствующий
порядок, лайки/обработка/сохранение без изменений — нет. Фильтры и сортировки
действуют на весь разрешённый результат, а не только на выданную страницу.
