# R20: дополнения страницы просмотра

Статус: `done` по функциональным профилям. Запрошено и согласовано 2026-11-18.
[Референс](../../../frontend/Reference/clipboard_2026-11-18_10-12.png).

1. Справа — видео из главной ленты, без алгоритма рекомендаций/новых фильтров.
   На телефоне список располагается под основной областью.
2. Подсветка страницы по средним цветам текущих кадров, без отдельного потока
   или повторного запуска видео. Не сохранять кадры в файлы/storage/Query.
3. Закладка — выбор своих плейлистов для любого доступного видео, в том числе
   чужого. Сохранение сразу, окно остаётся открытым; создание нового плейлиста
   автоматически включает текущее видео. [Требования бэкенду](../../frontend/watch-save-backend-request.md).

Все три части подключены к готовым API и реальным кадрам плеера;
[код, жизненный цикл, профиль и ограничения](../../frontend/watch-enhancements.md).
Новый профиль прошёл: Chromium 42, Firefox 41 проверка; разница — CDP-эмуляция
reduced-motion только в Chromium. Регрессия обоих браузеров прошла: обычное
создание плейлистов — по 56, контролы плеера — по 38, доступ — по 45,
позиции просмотра — по 33 проверки. Исправлена гонка быстрых команд громкости.
Генерация SDK, сборка/типы, ESLint/Prettier исходников, синтаксис/формат профиля,
ссылки документов и git diff --check прошли в Docker. Бэкенд приложения и
библиотеки не менялись; визуальную приёмку выполняет пользователь.

Проверено: реальные карточки/продолжение/ошибки справа, права/F33 и смена видео;
подсветка из декодируемого HLS, пауза/перемотка/hidden tab/уход/отказ/смена личности;
освобождение таймеров/ресурсов, отсутствие новой записи прогресса/лишнего потока.
Для сохранения — серверные подтверждения, пустые/ошибочные списки, cursor по 20,
выбор за первой страницей, идемпотентный повтор/CSRF/права, новый плейлист с видео,
отзыв/поздний ответ/выход, мышь/клавиатура/телефон. Внешний вид проверяет пользователь.
