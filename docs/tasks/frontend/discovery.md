## F09. Показывать главную ленту с карточками

**Описание.** Посетитель видит доступные видео и переходит к просмотру или каналу автора.

**Требования.** Геометрия карточек, превью, типографика, сетка, состояния наведения/
фокуса и переходы соответствуют утверждённому YouTube-референсу для ПК/мобильного веба.
Данные приходят из B23: только публичные опубликованные нескрытые видео с готовым
качеством, новые сначала по завершению загрузки исходника. Персональных рекомендаций нет.
Карточка не показывает фиктивных метрик или доступность ещё не готового видео.

**Приёмка.** Работают переходы с карточки/автора и применимые состояния ожидания,
пустой ленты и ошибки. Проверены длинное название и разные пропорции исходника,
порядок новых/старых, отсутствие private/hidden. После отказа доступа старая
карточка не раскрывает закрытые данные. API возвращает cursor и порции по 20
по ADR-0059; способ вызова следующей порции в UI разбирается в Q07.

## F10. Искать и показывать видео, каналы и плейлисты

**Описание.** Посетитель вводит запрос и получает соответствующую выдачу.

**Требования.** Поисковая строка и переход к выдаче доступны из оболочки.
Запрос восстанавливается из URL при прямом открытии и навигации браузера.
Внешний вид строки/результатов и её подтверждение следуют F01.
Совпадение по части текста без регистра: видео/плейлист — название,
канал — имя или `@тег`. Email, описания, субтитры не используются как поля поиска.
В результатах только разрешённые типы данных по B24; плейлисты — только public.

**Приёмка.** Проверены три типа карточек и переходы из них, неполный запрос,
другой регистр, пустой результат, ошибка и быстро меняющиеся запросы.
Поздний ответ старого запроса не заменяет новый. Private-видео не становится
результатом для приглашённого, unlisted/private-плейлисты не обнаруживаются.
Поисковые подсказки и дополнительные виды результатов вне ТЗ не добавляются.

## F11. Выбирать фильтры и сортировки

**Описание.** Посетитель управляет согласованными ограничениями поиска.

**Требования.** Панель/меню фильтров, выбранные состояния и закрытие повторяют F01,
но содержат согласованный набор нашего проекта. Тип, длительность, период —
по одному значению; особенностей может быть несколько. Все применимые условия
сочетаются через «И», выбор отражается в запросе и восстанавливаемом состоянии поиска.
Сортировки — по созданию и изменению, новые сначала. Периоды считает сервер по МСК.
Полный набор и границы — [поиск](../../project/search.md): менее 3, 3–20,
более 20 минут; сегодня/неделя/месяц/год; 4K/HD/субтитры/HDR.

**Приёмка.** Отображённый выбор соответствует отправленному и серверному результату,
не теряется при навигации назад/вперёд. 4K + HDR требует готового 2160p HDR,
ровно 3/20 минут принадлежат средней группе. Не выдавать свойства исходника
за готовность. Каналы/плейлисты не фильтруются по длительности/качеству их видео.
Обработка/лайки не изображаются как новая дата изменения. Фильтрация не ограничивается
уже загруженными карточками. API использует cursor по 20 (ADR-0059),
поведение загрузки следующей порции в интерфейсе согласуется по Q07.
