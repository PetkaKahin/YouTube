# R21: уточнение интерфейса просмотра

Статус: `done` по функциональным профилям, запрос и ответы пользователя от 2026-11-18.

- Подсветка меняет также хедер тем же цветом текущего видео.
- Выбор плейлистов — выпадающий список у закладки, без модальной блокировки страницы.
  Сохранение немедленное, список остаётся открыт; создание с включением сохраняется.
- Кнопки и плеер оформляются по новым снимкам:
  [111025](../../../frontend/Reference/Снимок%20экрана_20261118_111025.png),
  [111053](../../../frontend/Reference/Снимок%20экрана_20261118_111053.png).
  Не переносить отсутствующие в ТЗ главы/режимы/действия из полного YouTube.
- При переходе на обычный watch запрашивается автозапуск с текущим звуком;
  запрет браузера оставляет доступный ручной запуск, без обхода политики/скрытого успеха.
  Служебный просмотр не получает автозапуск автоматически.
- Дизлайк согласован: без публичного счётчика, взаимоисключается с лайком,
  повтор снимает отметку. [Требования к API](../../frontend/dislikes-backend-request.md).

браузеров прошла: контролы — по 38, лайк — по 36 проверок.
Сборка/типы, ESLint/Prettier, синтаксис профиля/помощников, ссылки документов
