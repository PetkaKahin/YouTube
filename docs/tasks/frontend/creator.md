# Настройки видео автора

F26–F28 — `done`: список своих видео/черновиков, общая страница настроек,
блоки превью, плейлистов и email подключены к загрузке и настройкам. Источники: [Video](../../backend/modules/video.md),
[Channel](../../backend/modules/channel.md), [экраны](../../frontend/screens.md).
Зависимости и общая приёмка — [реестр](README.md).
Код/проверки — [свои видео и настройки](../../frontend/video-settings.md),
[параметры видео](../../frontend/video-options.md); для Studio
достаточно общего сходства по [ADR-0068](../../decisions/0068-studio-visual-scope-and-video-options.md).

## F26. Открывать и сохранять настройки своего видео

**Описание.** Автор меняет название, описание, видимость и согласованные настройки видео.

Бэкенд входа в настройки готов по Q50:
[раздельные списки своих видео и черновиков](../../backend/own-videos.md).
Вкладка Studio и клиент подключены. Профиль настроек прошёл в Chromium/Firefox;
проверены отдельные выдачи 20/20/1, права, ошибки и отмена записи, int64,
Unicode, CSRF, очистка кэша, клавиатура и телефон. Блоки F27/F28 дополнительно
проверены общим профилем параметров в обоих браузерах.

**Требования.** Форма и взаимодействия соответствуют F01, набор полей ограничен B12.
Текущие данные загружаются с сервера, отправка и результат сохранения различимы.
Только public/private, без снятия модерационного скрытия через настройки.
Доступ ко всем своим плейлистам/разрешениям привязывается к текущему владельцу.
Вход — список контента Studio по Q50; обычный канал не содержит закрытого управления.
Дополнительные разделы ЛК не создаются.

**Приёмка.** Проверены автор/посторонний, прямая ссылка, медленная загрузка,
реальная/пустая правка и отказ сохранения. Ошибка не заменяет серверные данные
несохранённым успехом. Чужие данные не мелькают до отказа доступа,
метаданные не исполняются как HTML и не обходят скрытие.

## F27. Выдавать и отзывать приватный доступ по email

**Описание.** Владелец управляет разрешёнными адресами при загрузке и в настройках видео.

**Требования.** По одному поведению формы для обоих мест, референс — F01.
Принимается корректный email, включая ещё не зарегистрированный; имена, теги,
аватары и статус регистрации получателей не ищутся/не показываются.
Список показывает введённые адреса без раскрытия аккаунтов. Добавление/отзыв
подтверждает B21; повтор адреса не создаёт дубль. Подтверждения почты нет.

**Приёмка.** Зарегистрированный и новый адрес дают одинаковое видимое поведение.
Проверены неверный формат, повтор/другой регистр, ошибка добавления/отзыва
и смена видео до ответа. UI не объявляет неподтверждённый отзыв успешным,
известные сведения другого аккаунта не подставляются в форму.

## F28. Выбирать плейлисты независимыми галочками

**Описание.** В настройках своего видео автор управляет его включением в свои плейлисты.

**Требования.** Согласованный элемент — выпадающий список с независимыми галочками,
включая текущее состояние. Можно выбрать несколько, все или ни одного;
отдельная кнопка «выбрать все» не предполагается без референса.
Есть путь создания плейлиста F21 по выбранному UI. Снятие выбора удаляет только
соответствующую связь; сохранение не меняет другие включения или видимость видео.
Новые включения добавляются в конец, перетаскивания для смены порядка нет.

**Приёмка.** Проверены ноль/один/несколько/все, пустой список, новый плейлист,
повтор сохранения и ошибка. После ответа отмечен реальный результат B27;
состояния другого видео не переиспользуются. Повтор не создаёт дубль/новую позицию,
а удаление и повторное включение соответствует серверному добавлению в конец.
