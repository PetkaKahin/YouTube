# Бизнес-задачи фронтенда

Статус: декомпозиция подготовлена; **все F01–F33 — todo**.
Это описания, требования, зависимости и приёмка T09/T10 из [общего плана](../README.md).
Минимальный Vue bootstrap не означает готовность пользовательских сценариев.
Код, библиотеки UI/плеера, API-контракты и точная раскладка экранов здесь не проектируются.

UI и видимое поведение — **1 в 1 как YouTube** для функций [ТЗ](../../project/requirements.md),
ПК/мобильный веб, пока только тёмная тема. Критерии и согласованные исключения —
[соответствие YouTube](../../frontend/youtube-parity.md).
Простота нашего бэкенда не оправдывает упрощённый интерфейс или фиктивные действия.
Список B-ID ниже ссылается на [бизнес-задачи бэкенда](../backend/README.md);
их готовность необходима для полной интеграционной приёмки.

## Общие требования

- Пользователь получает реальные данные нашего сервера. Ошибки и ограничения
  не скрываются за фиктивным успехом; отображаемый прогресс соответствует известным данным.
- Все доступные по ТЗ действия работают мышью, клавиатурой и на сенсорном экране.
  У полей/кнопок есть понятные подписи, фокус виден и возвращается после закрытия диалога.
- Каждому экрану нужны применимые loading/empty/error/unauthenticated/forbidden/not-found
  и состояния отправки формы. Ожидание не выдаётся за пустой результат.
- Двойное нажатие, повтор/ошибка запроса и поздний ответ не создают видимых дублей,
  не переносят результат в другое видео/аккаунт и не подтверждают неуспешное изменение.
- Секрет сессии не хранится в localStorage/Pinia; секреты сервисов не попадают в браузер.
  UI не является источником права доступа и не заменяет серверную проверку.
- Пользовательский текст показывается как данные; ошибки не раскрывают приватные
  названия, ссылки, отправителей жалоб или наличие аккаунта по email в форме разрешений.
- Переходы и история браузера открывают соответствующее состояние, прямое открытие
  разрешённого экрана работает после загрузки приложения. URL не содержит паролей,
  токенов сессии или данных формы регистрации. Поисковое состояние восстанавливается из URL.
- Сходство с YouTube оценивается по зафиксированным референсам, включая поведение,
  а не только по одной картинке. Список исключений — в документе соответствия.
