# Фоновые задания: ошибки и повторный запуск

Статус: реализован технический журнал и middleware Procrastinate; worker
и автоматическое обслуживание подключаются следующим этапом.
Параметры согласованы в [ADR-0035](../decisions/0035-worker-policy-and-job-errors.md),
хранение — [ADR-0036](../decisions/0036-durable-job-error-history.md).

## История и диагностика

Сохраняется каждая неудачная попытка, даже перед последующим успехом.
История PostgreSQL не зависит от очистки очереди, рестартов и потери Valkey.
Очистки по сроку нет. При недоступной БД безопасное событие остаётся
в буфере постоянного Docker-тома и переносится после восстановления.

Сначала событие синхронизируется на диск, затем отдельно коммитится в БД;
подтверждённый файл удаляется. UUID предотвращает дубли после потери commit.
Повреждённые записи сохраняются; отказ буфера не выдаётся за успешную запись.
Блокировки и отмена не должны терять принятые события.

Журнал содержит bigint ID задания, попытку, этап, время, безопасную причину
и позиции стека без текста исключений, локальных переменных, исходного кода,
паролей, cookie и подписанных URL. Успех не удаляет прошлые ошибки.
Для потерянного worker подготовлен формат наблюдения без выдуманного traceback.

Код: [контракты](../../backend/src/common/contracts/job_errors.py),
[журнал](../../backend/src/common/infrastructure/job_errors.py),
[middleware](../../backend/src/common/infrastructure/job_monitor.py),
[миграция](../../backend/migrations/versions/0002_job_errors.py).
Middleware передаёт исключение Procrastinate для retry/abort, защищает запись
при отмене, останавливает worker при отказе буфера. Перед запуском нужно
вызвать configure_safe_queue_logging(): обычные логи библиотеки содержат
аргументы, результаты и исключения.

## Будущий ручной повтор

Админ-панель и её API отложены в [T12](../tasks/T12-job-administration.md).
Диагностика доступна только admin; гость, user и moderator не получают
доступа. Автору предназначена только безопасная причина ошибки его видео.
Повтор должен сохранять историю и готовые результаты, выдерживать
конкурирующие нажатия, проверять права и технические ограничения.
Выполняются только доверенные зарегистрированные задачи, не произвольные
функции/аргументы; действие администратора прослеживается.
Бюджет попыток после ручного повтора остаётся Q36, детали UI — Q07.
