# Проверка пакетов и доверенные слепки дорожек

Реализовано 2026-11-14: расширение первичного инспектора B10/B13 по
[ADR-0033](../decisions/0033-compressed-content-fingerprints.md).

## Контракт этапа

До целевой конвертации worker читает все сжатые пакеты всех дорожек локального
исходника. FFprobe выдаёт SHA-256 payload и codec extradata, точные PTS/DTS/duration,
флаги и технические side data. Описательные теги не запрашиваются; язык, disposition,
поворот, цвет, HDR, каналы и параметры декодирования сохраняются.
Чтение пакетов не заменяет проверку декодером при последующей конвертации.
Ошибка демультиплексора, corrupt-флаг, неполный отчёт или пустая видеодорожка
не дают подтверждённого совпадения.

Формат слепка `compressed-v1`: однозначный JSON с сортировкой ключей и рамкой
длины каждого элемента. Времена — сокращённые рациональные числа, без float.
Внутри дорожки время относительно первого DTS (либо PTS); смещения дорожек
относительно общей начальной точки сохраняются в составе исходника.
Разное чередование пакетов разных дорожек не меняет их слепки.
Неизвестные side data требуют дополнительного SHA-256 всего исходника в слепке:
это консервативная защита от ложного совпадения, без отказа во входном формате.
Их содержимое сохраняется только как digest: неизвестная запись может содержать
описательные строки, которым не место в постоянном техническом отчёте.
Такая же защита применяется при нераскрытой extradata, неизвестном типе дорожки
или отсутствии точного времени пакета. Возможны лишние несовпадения; удалять
защиту ради большей дедупликации без точного представления этих данных нельзя.
Даже stream copy может менять codec extradata; это техническое изменение,
в отличие от замены только описательных тегов, и совпадение не гарантируется.

Длительность определяется по PTS/DTS и концу пакетов аудио/видео, с учётом
доступного start_pts; ограничение 3600 с проверяется также по заголовкам.
Для пакета без timestamps используется последовательная шкала, при отсутствии
видеодлительности — известный FPS; такой вход получает source guard.
Необнаружимая по демультиплексированию ошибка сжатого кадра может проявиться
только при декодировании. Этот этап не объявляет B10 завершённой.

## Постоянные данные

Общие записи дорожек уникальны по версии и digest. Запись состава исходника
уникальна по digest упорядоченных дорожек, смещений, языка и disposition.
Связь каждой передачи с составом и дорожками сохраняется одной транзакцией
с завершением актуальной попытки. Поздний worker не создаёт общих записей.
Конкурентное совпадение использует уникальные ограничения PostgreSQL.
Состояние/номер попытки очереди удерживаются `FOR SHARE` до конца транзакции:
recovery не может сменить поколение между проверкой допуска и фиксацией результата.
Если recovery уже меняет запись, поздний finish/fail ждёт и повторно проверяет
условие по новой версии строки; общий результат не создаётся.
Общие дорожки фиксируются в порядке digest, независимо от порядка входных потоков,
чтобы конкуренция составов с разным порядком дорожек не создавала взаимных блокировок.
Публикации, права и даты независимы; хеши и ID общего содержимого не выдаются API.

Ранее проверенные только заголовки исходники повторно ставятся в media очередью
обслуживания. Старая успешная первичная проверка не считается полным слепком.
Сам этап слепков не формирует готовые AV1/HLS и не удаляет оригинал.
Планирование и физическое переиспользование закодированных дорожек подключены
следующим этапом — [AV1/AAC](encoding.md); защищённая выдача ещё впереди.
Отчёт инспектора версии 3 дополнен временной привязкой для кодирования,
формат слепка compressed-v1 остаётся прежним.

## Приёмка

Проверяются изменение title/artist без изменения слепка, изменение payload,
тайминга, аудио, субтитров, поворота/цвета; эквивалентные единицы времени,
вертикальное видео и несколько дорожек, граница 60 минут, повреждённый/обрезанный
файл, запрет вложенных URL, конкурентная фиксация, rollback/fencing/backfill.
Проверки выполняются в Docker с реальными PostgreSQL/RustFS/Procrastinate.

Код: [инспектор](../../backend/src/video/infrastructure/track_inspector.py),
[SQL и fencing](../../backend/src/video/infrastructure/processing.py),
[миграция](../../backend/migrations/versions/0008_track_fingerprints.py),
[проверки](../../backend/src/video/tests/test_track_fingerprints.py).
FFprobe получает только унаследованный FD локального исходника; протоколы
file/http/tcp не разрешены. XML создаёт фиксированный writer FFprobe с экранированием,
не пользовательский документ. Сырые ошибки/отчёты и пути в журнал не переносятся.
Основа — [официальные show_packets/show_data_hash/show_entries](https://ffmpeg.org/ffprobe.html),
документация и установленный FFprobe проверены 2026-11-14.

поколения очереди и защиты неизвестных side data профильная приёмка
инспектора/очереди/ресурсов повторена: 81 passed (45,09 с).
