# Moderation

Статус: причины жалоб, обновление существующей записи и возврат в очередь при повторной отправке
утверждены пользователем; остальные правила R07, R09 — базовая спецификация.

## Ответственность

Жалобы на видео, их рассмотрение и решение о скрытии. Модуль хранит жалобу,
инициатора, причину, состояние рассмотрения, решение и исполнителя в PostgreSQL.
Фактическое состояние скрытия принадлежит Video и меняется через `Video.public`.

## Базовые правила

- Вошедший зритель может пожаловаться на доступное ему видео, указав причину.
- Одна жалоба или большое число жалоб не скрывают видео автоматически:
  решение принимает модератор или администратор.
- Автор видео и обычные зрители не получают сведения об отправителе жалобы.
- Рассмотрение заканчивается отклонением жалобы либо скрытием видео с причиной.
- Скрытое видео исключается из главной, поиска, канала и доступного состава
  плейлистов; обычные прямые запросы к нему и HLS также закрываются.
- Владелец не может снять модерационное скрытие изменением видимости или метаданных.
- Рассмотрение и применение скрытия повторяемы без дублирования результата;
  сбой между решением и изменением Video не должен оставлять жалобу ложно завершённой.
- Доступ сотрудника к приватному видео допускается только для рассмотрения
  жалобы через отдельный серверный сценарий с записью исполнителя и основания.
  Обычные списки и плеер не предоставляют роли неограниченный просмотр.

Жалоба без автоматического удаления и анонимность для других пользователей —
нужная часть [справки YouTube](https://support.google.com/youtube/answer/2802027?hl=en),
проверена 2026-11-11. Ограничение служебного доступа и хранение решения —
проектная спецификация; это не описание внутренней реализации YouTube.

## Причины и повторная отправка

Утверждено пользователем 2026-11-12; [ADR-0016](../../decisions/0016-report-reasons-and-updates.md).

Допустимые причины:

- Спам / мошенничество.
- Оскорбления / травля.
- Насилие.
- Сексуальный контент.
- Авторские права.
- Другое.

Для пары «пользователь, видео» существует одна запись жалобы. Первая отправка
создаёт её, повторная обновляет ту же запись, включая актуальную причину
и время обращения. Отдельные пользователи могут жаловаться на одно видео,
но один пользователь не создаёт дубликатов своей жалобы.

Повтор после рассмотрения обновляет существующую запись и возвращает её
в состояние «ожидает рассмотрения». Предыдущее решение не считается решением
по обновлённому обращению. Если жалоба уже ожидает рассмотрения, её данные
обновляются в той же записи без создания второго обращения в очереди.
Q19 закрыт; [состояние вопросов](../../tasks/open-questions.md).
Обновление жалобы само по себе не меняет состояние скрытия видео.

## Граница и проверки

Только жалобы и скрытие видео: без страйков, отдельного сценария апелляций, автоматических санкций,
блокировки аккаунтов и правил монетизации. Возврат скрытого видео не добавляется
как пользовательское действие без отдельного требования.
Причины, обновление записи и повторное ожидание модерации согласованы.
Проверки: пользователь не открывает очередь модерации, отправитель не раскрывается,
скрытие действует на все пути чтения и обработки, повторная доставка не публикует видео обратно.
Дополнительно проверяются допустимые причины, одна запись на пару
«пользователь, видео» и обновление этой записи при повторной отправке,
в том числе при конкурентных запросах.
Для рассмотренной жалобы проверяется возврат в очередь после повторной
отправки; при повторе ожидающей жалобы в очереди остаётся одно обращение.
