# Последняя позиция просмотра

Статус: `done`. [Правила и HTTP-контракт](../frontend/watch-progress-backend-request.md)
согласованы пользователем для R18; фронтенд подключается отдельно.

Реализованы миграция 0026 и одна строка PostgreSQL на пару аккаунт/видео.
Хранятся фактическая позиция, доверенная длительность и время принятой записи.
Ноль и перемотка назад заменяют предыдущую позицию. Истории и счётчиков нет.

Запись удерживает разделяемую блокировку публикации и повторно применяет обычные
права просмотра; изменение приватности, разрешений или скрытия сериализуется
с ней. UPSERT сериализует конкурирующие записи одной пары; время задаёт сервер.
Метаданные публикации не меняются. Неизвестные поля и не finite числа запрещены.

Для уже отобранной страницы ленты/поиска/канала/плейлиста позиции читаются одним пакетным
запросом, только для текущего аккаунта. Порядок и cursor остаются прежними.
Обычный просмотр возвращает свою позицию после проверки прав. Гостю возвращается
null; чтения, предпросмотр и служебное воспроизведение ничего не записывают.

Новых библиотек, фоновых заданий и изменений медиапакетов не требуется.
Проверки относятся только к записи, выдаче позиций и изменённым интеграциям.

## Состав плейлиста

Исправлен 500 у непустого GET `/api/v1/playlists/{id}`: обязательное nullable поле
FeedCardResponse.watch_progress передаётся в HTTP из PlaylistVideo.watch_progress.
После отбора страницы Channel запрашивает позиции через Video.public.ReadWatchProgress
и преобразует их в свой PlaylistWatchProgress. Чтение позиций — одно на итоговую
страницу, включая проход нескольких пакетов недоступных видео. Порядок, cursor
и независимые права видео сохранены; чтения не создают и не обновляют прогресс.
Новых миграций нет.

Прошли **6 профильных HTTP-проверок**:
[регрессия плейлиста](../../backend/tests/test_playlist_watch_progress_http.py).
Проверены public/unlisted/private, гость/владелец/другой аккаунт, сохранённая
позиция и null, изоляция аккаунтов, отзыв private-доступа и скрытие, неизменность
метаданных/порядка, один запрос позиций для двух доступных видео среди 43 черновиков,
отсутствие записи при чтении и 500 без частичных данных при отказе БД.
Ruff, форматирование и Basedpyright затронутых файлов прошли.
