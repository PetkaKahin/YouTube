## Статусы и достоверность

- **Требование** — явно задано пользователем; менять без согласования нельзя.
- **Базовая спецификация** — описание поведения внутри ТЗ, подготовленное по его
  смыслу и указанным источникам YouTube; не означает, что код уже существует.
- **Открыто** — решение не принято; перед зависимой реализацией нужен ответ пользователя.
- **Реализовано** — существует в репозитории и подтверждено указанной проверкой.

Детальные правила живут у владельца модуля, общие границы — в ТЗ, причины — в ADR.
Изменение кода и обновление затронутых документов составляют одну задачу.
Команды добавляются как рабочие только после появления и проверки конфигурации.
