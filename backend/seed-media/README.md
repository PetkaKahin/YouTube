# Готовые видео для make seed

12 природных роликов, 1–4 минуты: AV1 HLS в 360p/480p/720p, отдельные AAC-дорожки
и по три WebP-превью. Набор занимает примерно 741 МиБ. Исходные полноразмерные
MP4 удалены; маленькие init.mp4 внутри HLS — части готового fMP4-пакета.

У каждого ролика есть каталог с bundle.json и дорожками по profile_key:
index.m3u8, init.mp4, segment_*.m4s и candidate_*.webp. Корневой manifest.json
версии 2 содержит SHA-256 bundle.json, а bundle.json — размеры/хеши всех файлов,
проверку исходника, слепки, профили кодирования, конфигурацию плана и артефакты.
Числовые ID исходной БД в связях плана заменены стабильными ключами профилей.

Файлы включены в общий Docker base и доступны в dev/prod без внешней сети.
Обычный make seed копирует их в RustFS и импортирует готовые метаданные через
Video.public, без FFmpeg и задач обработки. Подробнее —
[сценарий сидирования](../../docs/tasks/demo-seed.md).

Футажи предоставлены National Park Service. В описаниях видео сохранены
атрибуция «Courtesy of the National Park Service» и ссылка на источник.

| Набор | Источник и условия использования |
| --- | --- |
| 9 лесных футажей: папоротники, секвойи и ручьи | [Redwood](https://www.nps.gov/redw/learn/photosmultimedia/broll.htm): свободное использование HD-футажей в медиапроектах |
| 3 пейзажа: Мозаичный каньон, горы Панаминт, песчаные дюны | [Death Valley](https://www.nps.gov/deva/learn/photosmultimedia/b-roll-footage.htm): public domain |

Условия проверены 2026-11-16. До рендера Lost Man Creek перекодирован
в H.264/AAC и обрезан до первых 90 секунд, исходное разрешение сохранено.
У части роликов естественный звук, музыка не добавлялась. Лицензии, оригинальные
URL и сведения об исходниках сохранены в manifest.json. Сами готовые пакеты
получены обычным worker проекта; сидер не объявляет непроверенные файлы готовыми.
